# travel_d: 여행 부탁·방문 추억 카드 표정 에셋 명세

이슈 [#67](https://github.com/Allo-MJU/allo/issues/67) (상위 [#59](https://github.com/Allo-MJU/allo/issues/59)) · D 박찬 작성

> **상태: 시안 명세.** 7일 등 명세 수치는 검토용 제안이며 확정 규칙이 아니다. 크기·포맷·파일명은 A/B 합의 전까지 확정이 아니다. 기준은 디자인 시스템 [PR #48](https://github.com/Allo-MJU/allo/pull/48)의 12종과 와이어프레임 [PR #49](https://github.com/Allo-MJU/allo/pull/49)다. 두 PR은 아직 OPEN이다.

## 범위

- 캐릭터가 선호 지역으로 다음 여행을 부탁하고, 사용자가 다녀온 경험을 확인하거나 사진을 선택적으로 붙였을 때 보여줄 표정·포즈와 카드 일러스트.
- 제외: 3D 모델·리깅, 신규 종, 경제 보상.

## 지키는 원칙

- 방문 확인은 사용자의 명시 행동이다. 현재 위치나 수집 지역만으로 실제 방문을 증명하는 그림·문구를 쓰지 않는다.
- 캐릭터가 사진 속 장소·사람·활동을 인식한 것처럼 그리거나 쓰지 않는다. 반응은 "보여줘서 고맙다" 수준에서 멈춘다.
- 대사 시안에는 `reviewedBy`나 검수 완료를 기록하지 않는다. 최종 검수자는 팀이 정한다.

## 미결정 항목

D09: 부탁 간격, 지역·속성 취향, 방문 확인 표현, 사진 선택과 반응 문구. D11: 요약·버전. 결정 전에는 시안으로만 둔다.
