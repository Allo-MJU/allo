# hatch_d: 호감도 부화 반응과 실패 결과 에셋 명세

이슈 [#65](https://github.com/Allo-MJU/allo/issues/65) (상위 [#57](https://github.com/Allo-MJU/allo/issues/57)) · D 박찬 작성

> **상태: 시안 명세.** 크기·포맷·파일명은 D의 제안이며 A/B 합의 전까지 확정이 아니다. 캐릭터는 디자인 시스템 [PR #48](https://github.com/Allo-MJU/allo/pull/48)의 12종을, 화면은 와이어프레임 [PR #49](https://github.com/Allo-MJU/allo/pull/49)의 품기(3번)·부화(5번)·부화 연출 5컷(23번)을 기준으로 한다. 두 PR은 아직 OPEN이다.

## 범위

- 폰 대화로 목적지·기분·여행 기대 주제에 답한 뒤 보여줄 짧은 캐릭터 반응, 마감 결과(성공/실패) 표현.
- 제외: 3D 모델·리깅, 새 경제·보상 표현.
- 반응은 주제마다 구분되어 보이되, 답의 진위나 아이의 감정을 평가하는 인상을 주지 않는다.

## 실패 표현 주의점

- 비난이나 죄책감을 유발하는 표정·문구를 쓰지 않는다.
- 이미 부화해 보유 중인 캐릭터가 사라졌다고 오해하지 않게 한다. 실패는 해당 알에만 적용하고 이미 얻은 캐릭터와 거점은 유지한다(명세 5.5절).
- 다음 알로 이어지는 화면 흐름은 D05 결정 뒤에 정한다.
