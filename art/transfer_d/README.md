# transfer_d: 차량 낚시 대기와 폰 이동 에셋 명세

이슈 [#64](https://github.com/Allo-MJU/allo/issues/64) (상위 [#56](https://github.com/Allo-MJU/allo/issues/56)) · D 박찬 작성

> **상태: 시안 명세.** 아래 크기·포맷·파일명은 D의 제안이며 A/B 합의 전까지 확정이 아니다. 원화·모션 파일은 합의 뒤에 만든다. 캐릭터 외형은 디자인 시스템 [PR #48](https://github.com/Allo-MJU/allo/pull/48)의 12종(`character-production-01`)을 그대로 쓰고, 화면 위치는 와이어프레임 [PR #49](https://github.com/Allo-MJU/allo/pull/49)를 따른다. 두 PR은 아직 OPEN이다.

## 범위

- 이미 부화한 보유 캐릭터가 차량 대기 화면에서 낚시하는 분위기 연출, 호출이 승인되면 차량 장면에서 나가 폰 화면에 들어오는 표시.
- 제외: 낚시 미니게임, 물고기 획득, 보상, 3D 모델·리깅, 신규 종.
- 호출 음성·명령이 성공했는지를 아트만으로 단정하지 않는다. 확인이 늦어지는 상태를 성공처럼 그리지 않는다.

## 상태표

| 상태 | 장면 | 표현 | 비고 |
| --- | --- | --- | --- |
| `fishing` | 차량 | 낚시 대기 포즈, 작은 반복 움직임 | 정차 중 Pleos 화면. 주행 중 허용 범위는 D07에서 A와 결정 |
| `called` | 차량 | 호출을 알아들은 듯 고개를 드는 포즈 | 승인 전에는 쓰지 않는다 |
| `leaving` | 차량 | 차량 장면에서 나가는 표시 | 이동 완료가 아니라 "이동 중"만 말한다 |
| `arriving` | 폰 | 폰 화면에 들어오는 표시 | 폰 저장 후 차량 확인 흐름(`transferResult`)과 순서가 맞아야 한다 |
| `pending` | 차량·폰 | 확인 지연 표시. 성공 표현 금지 | 통신 지연 폴백 |
| `static` | 공통 | 같은 캐릭터의 정지 이미지 | 로딩, 미지원 종, 에셋 누락 폴백 |

같은 개체로 보이도록 상태가 바뀌어도 종 실루엣, 몸 색(`species.*.base`), 표정 계열을 유지한다.

## 파일 목록 제안

| 파일 | 용도 | 투명 | 비고 |
| --- | --- | --- | --- |
| `{id}_fishing.png` | 차량 낚시 대기 | 예 | |
| `{id}_called.png` | 호출 인지 | 예 | |
| `{id}_leaving.png` | 차량 퇴장 표시 | 예 | |
| `{id}_arriving.png` | 폰 진입 표시 | 예 | |
| `{id}_static.png` | 폴백 | 예 | `phone/assets/species/`가 지금은 비어 있어 재사용할 파일이 없다. 생기면 그것을 쓴다 |

`{id}`는 디자인 시스템의 12종 id다. 현재 `data/species.json`과 겹치는 종은 6종(`road_sprout`, `puddle_pip`, `lamp_moth`, `storm_lantern`, `highway_comet`, `sea_mist`)뿐이며 나머지 6종 데이터는 C가 정한다(design-system 3-2절). 그 전까지는 이 6종 기준으로만 파일명을 확정한다. 파일명 규칙의 출처는 `art/README.md`다. 12종 전부를 만들지는 정하지 않았다. 첫 구현 화면에 나오는 종부터 만든다.
