# 알로(ALLO) 아트 디렉션 · 캐릭터 바이블 · UI 설계

> 2026-11-05 D(박찬) 작성 · **초안, 팀 검토 전.**
> 종·속성·등급·태그는 [`data/species.json`](../data/species.json)과 [`schema.md`](./schema.md)를 따른다. 이 문서는 그 위에 **어떻게 보이는지**만 정한다. 종 구성이나 판정 규칙을 바꾸지 않는다.
> 시안(브라우저로 연다): [`characters.html`](../art/design/characters.html) 캐릭터·알 · [`wireframes.html`](../art/design/wireframes.html) 화면 · [`icon/`](../art/design/icon/) 앱 아이콘 SVG

## 0. 이 문서가 지키는 것

1. 생물은 **12종**이다. 속성 3(water·dark·normal) × 등급 3, 그리고 복합 조건 희귀종 3. 이 문서에서 종을 더하거나 빼지 않는다
2. 판정은 폰의 `allo_core`가 한다. 아트는 판정 결과(`speciesId`)를 그릴 뿐 결과에 영향을 주지 않는다
3. 성격과 말버릇은 [`dialogue-style.md`](./dialogue-style.md) 2절의 표가 원본이다. 외형은 그 성격이 보이게 그린다
4. 주행 중에는 정교한 조작이나 빠른 반응을 요구하는 화면을 만들지 않는다
5. 희귀도는 결제로 얻지 않는다. 확률형 연출(뽑기 룰렛, 카드 뒤집기)을 쓰지 않는다

## 1. 디자인 원칙과 근거

모든 디자인 결정은 아래 일곱 원칙으로 검토한다. 각 원칙의 수치는 9절(UI 토큰)과 12절(검수)에서 구체화한다.

| # | 원칙 | 왜 | 근거 |
| --- | --- | --- | --- |
| 1 | **실루엣으로 구분한다** | 12종이 같은 몸을 공유하면 도감 칸 크기에서 덩어리로 보인다. 수집 게임은 형제 캐릭터끼리 확실히 달라야 한다 | 실루엣 테스트(검게 채워도 누군지 알아보는지, 실제 표시 크기에서) · 형태 언어(주 형태 1 + 보조 형태 1) — [CoArtist](https://coartist.net/blog/character-design-readability-silhouette-shape-language-contrast), [Nasty Rodent](https://nastyrodent.com/stylized-3d-characters-art-direction-principles/) |

| 5 | **진행의 끝을 보여 준다** | 끝이 없는 진행 바는 남은 양을 알 수 없다 | Pokémon GO 알 진행 바 비평 — [2016 UI 분석](https://dylansunkel.wordpress.com/2016/07/25/pokemon-go-thoughts-for-improving-ui/) |
| 6 | **방치해도 벌을 주지 않는다** | 아이 대상 교감 게임에서 영구적인 슬픔·죄책감은 해결할 수 없는 부담이 된다 | Neko Atsume 분석 — [단순성](https://alexiamandeville.medium.com/game-design-breakdown-the-simplicity-of-neko-atsume-a8616a937a47), [사용성](https://medium.com/@laurielepham/neko-atsume-a-lesson-in-universal-usability-4c54a1507a84) · `dialogue-style.md` 애착 경계 |
| 7 | **차 화면은 한눈에** | 운전자 시선은 한 번에 2초, 작업 전체 12초 이내 | NHTSA 가이드 · [Android 차량 앱 품질](https://developer.android.com/docs/quality-guidelines/car-app-quality) · Pleos의 단순한 아이콘 중심 원칙 — [Hyundai](https://www.hyundai.news/eu/articles/press-releases/pleos-connect-infotainment-system.html) |

**연령 구간.** NN/g는 6~8세와 9~12세를 나눠 설계하라고 한다. 알로는 한 UI를 쓰되, 6~8세 기준으로 **조작**(큰 버튼, 스크롤 없음, 글자보다 아이콘)을 맞추고 9~11세 기준으로 **수집 깊이**(특별 등급, 길 카드, 영어 이름)를 맞춘다. 유아스럽게만 보이면 9~11세가 이탈한다(검증 안 된 가설 — 아이 테스트로 확인).

> Pleos 앱 디자인 가이드는 공개 문서를 찾지 못했다. Pleos Playground 개발자 포털에 있을 가능성이 높다(A 확인 필요). 그전에는 Android for Cars 가이드를 대용으로 쓴다.

## 2. 아트 디렉션 — A Gentle Journey

**스타일:** 소프트 3D, 파스텔 점토, 봉제인형 같은 질감.

- 둥글고 통통한 실루엣, 부드러운 그림자, 은은한 하이라이트
- 단순하지만 기억에 남는 얼굴: 큰 둥근 눈, 작은 입, 복숭앗빛 볼
- 위협적인 요소 금지: 날카로운 이빨·발톱·불꽃, 뾰족한 원뿔형 뿔·갈기, 큰 뿔과 날개, 갑옷과 금속 장식
- 화면 전체가 어둡고 무거운 분위기 금지

참고하는 것은 표현 방식뿐이다. **기존 IP의 캐릭터, 이름, 형태를 복제하지 않는다.**

### 2-1. 레퍼런스 시트 (2026-11-05)

AI 이미지 생성으로 만든 시트다. 개별 PNG가 아니라 **스타일 기준 이미지**이고, 최종 에셋은 종별로 다시 생성한다. 이미지 파일은 도구·IP 조건 확인 전이라 레포에 올리지 않았다(작성자 로컬 `art/design/ref/`). 회의에서 공유한다.

**스타일 확정 사항** (시트 기준)
- 눈: 크고 둥근 짙은 브라운, 흰 하이라이트 2점(큰 점 1, 작은 점 1)
- 포즈: 앉은 3/4 정면. 12종이 같은 카메라 각도·크기·바닥 기준선을 쓴다
- 머리·등 돌기: 둥글고 뭉툭하게

### 2-2. 남은 수정 (생성 에이전트에게 전달)

| 대상 | 문제 | 고칠 방향 |
| --- | --- | --- |
| 산정령 | 눈썹이 찌푸려져 화난 얼굴로 읽힘. 뿔이 뾰족한 원뿔 | 눈썹 없는 반쯤 감은 눈, 둥글고 뭉툭한 바위 뿔 |

| 물 계열 5종 · dark 3종 | 같은 속성끼리 색이 비슷해 도감 칸에서 헷갈릴 수 있음 | 4-2절 실루엣 포인트를 더 크게 (특히 꼬리·머리) |

| look 포즈 | 작은 이미지에서 창밖을 가리키는지 확인 불가 | 모든 종 같은 방향(오른쪽)으로 먼 곳을 가리킴 |

## 3. 컬러 시스템

### 3-1. 속성 색 (캐릭터)

| 역할 | 이름 | HEX | 쓰는 곳 |
| --- | --- | --- | --- |
| 바탕 | Cream | `#FFF0D8` | 캐릭터 배와 얼굴, 알 기본색 |
| normal 속성 | Sage | `#B9D0B9` | normal 종의 몸·뿔·날개·무늬 (산정령은 스톤 그레이 + 이끼 초록) |
| water 속성 | Sky | `#A9D4F1` | water 종의 몸·뿔·날개·무늬 |
| dark 속성 | Lavender | `#C9B9E8` | dark 종의 몸·뿔·날개·무늬 |
| 포인트 | Peach | `#F5B99F` | 볼 홍조, 스카프 |
| 포인트 | Butter Yellow | `#F4D98B` | 빛, 별, 랜턴, 진행 |
| 외곽선·글자 | Warm Brown | `#66584D` | 눈, 선, 본문 글자 |

- 비율: 크림 65%, 속성색 25%, 포인트 10%
- 배는 항상 Cream으로 밝게 둔다. dark 속성도 순검정 금지
- 발광은 네온이 아니라 Butter Yellow 계열의 은은한 빛
- **같은 속성 안에서는 색이 아니라 실루엣으로 구분한다** (원칙 1, 4-2절)

### 3-2. 희소도 배지 (UI) — 색 + 모양 + 글자

| 표시 등급 | 색 | HEX | 모양 | 글자 |
| --- | --- | --- | --- | --- |
| 일반 | 초록 | `#A8D5A2` | ★ | 일반 |
| 희귀 | 파랑 | `#9CCBF0` | ★★ | 희귀 |
| 초희귀 | 노랑 | `#F4D98B` | ★★★ | 초희귀 |
| 특별 | 분홍 | `#F2A7C3` | 왕관 | 특별 |

- 배지는 색, 모양, 글자를 함께 쓴다. 도감 칸처럼 좁은 곳은 모양만 남긴다(색 + 모양)
- 회색조로 봐도 등급이 구분돼야 한다 (12절 검수)
- 속성도 같은 규칙: 🌿 땅·길 / 💧 물 / 🌙 밤 아이콘을 색과 함께 쓴다

### 3-4. 차 화면 색

차 화면(`car/.../ui/AlloTheme.kt`)은 지금 밤하늘 남색(`#12142B`) 바탕이다. 야간 운전 중 실내 눈부심을 줄이려면 어두운 바탕이 맞으므로 **바탕은 유지하고 강조색만 맞춘다.** 강조색은 Butter Yellow `#F4D98B`, 보조 글자는 Cream `#FFF0D8`이다. 정차 화면의 캐릭터 카드만 크림 카드로 띄운다. 실제 수정은 A가 한다.

## 4. 공통 체형과 실루엣

### 4-1. 공통 체형

12종은 같은 몸을 공유한다. 도감에 나란히 놓았을 때 같은 세계의 생물로 보여야 하기 때문이다.

| 부위 | 기준 |
| --- | --- |
| 비율 | 약 2.5등신. 머리가 몸보다 조금 크다 |
| 머리 | 둥근 형태. 위에 둥글고 뭉툭한 돌기 (종별로 개수와 모양이 다름) |
| 몸통 | 통통한 타원. 배는 Cream |
| 눈 | 크고 둥근 짙은 브라운, 흰 하이라이트 2점. 종별 눈매는 반쯤 감김·처짐·찡긋 등으로 구분 |
| 입 | 짧은 곡선. 종별로 모양이 다름 |
| 볼 | Peach 홍조. 산정령만 최소화 |
| 날개 | 작고 둥글다. 등 뒤로 살짝 보인다 |
| 꼬리 | 짧고 통통하다. **끝 모양으로 종을 구분한다** |
| 발 | 짧고 둥글다. 발톱 금지 |
| 포즈 | 앉은 3/4 정면. 12종 모두 같은 카메라와 바닥 기준선 |

### 4-2. 종별 실루엣 포인트

몸은 같고 **외곽선을 깨는 곳 한두 군데**로 종을 구분한다. 종마다 주 형태 하나, 보조 형태 하나, 쓰면 안 되는 형태 하나를 정한다. 모든 종의 금지 형태 공통값은 "뾰족한 삼각형"이다(위협적으로 읽힘).

| 종 | 주 형태 | 실루엣을 깨는 곳 | 금지 |
| --- | --- | --- | --- |
| 길싹이 | 원 | 머리 위 잎 뭉치 | 뾰족한 잎 끝 |
| 다리뛰기 | 원 | 등의 아치 3개 + 스카프 꼬리 | 길게 선 귀 |
| 산정령 | 둥근 사각(바위) | 넓고 낮은 몸 + 뭉툭한 바위 뿔 | 원뿔 뿔 |
| 웅덩이삐약 | 원 | 머리 위 물방울 하나 | 큰 날개 |
| 강미끄럼 | 긴 타원 | 몸보다 긴 지느러미 꼬리 | 짧은 꼬리 |
| 물결지기 | 원 | 머리 조개 + 파도 날개 | 날카로운 지느러미 |
| 등불나방 | 원 | 더듬이 2개 끝의 구슬 | 뿔 |
| 터널나방 | 둥근 사각 | 구슬 뿔 3개 + 꼬리 랜턴 | 더듬이 |
| 별부엉이 | 원 | 부엉이 귀깃 2개 | 뾰족한 귀 |
| 폭풍등 | 원 | 빗방울 왕관 + 랜턴 꼬리 | 번개 모양 |
| 고속혜성 | 물방울(앞으로 기운) | 뒤로 길게 뻗는 혜성 꼬리 | 날카로운 꼬리 끝 |
| 바다안개 | 구름(원 여러 개) | 머리·꼬리의 구름 뭉치 | 매끈한 외곽선 |

**통과 기준:** 76px 도감 칸 크기에서 검게 채운 12종을 보고 5초 안에 이름을 맞힌다 (12절).

"표시 등급"은 아트와 도감 배지의 이름일 뿐이다. 카탈로그 tier 1·2·3을 일반·희귀·초희귀로 부르고, 환경 태그 2개 이상이 필요한 종을 특별로 부른다. 데이터는 바꾸지 않는다. 도감 카드의 부제는 지형이 아니라 위 **출현 조건**을 쓴다(예: 웅덩이삐약 "비", 폭풍등 "비 + 터널"). 길싹이와 다리뛰기는 "어디서든", 산정령은 "부드러운 주행"이다.

> **C 확인 필요:** 부화한 개체의 tier(`/game.tier`)와 종의 카탈로그 tier가 다를 수 있다(PR #29 결정 항목 2). 아트는 **종 기준**으로 한 벌만 그린다. 도감 배지가 어느 tier를 표시할지는 C가 결정하면 따른다.

성격 한 줄은 `dialogue-style.md`에서 가져왔다. "베이스"는 처음 구상한 드래곤 10종(14절) 중 이어받은 디자인이다.

#### normal — Sage 계열 · 땅과 길

**길싹이 `road_sprout`** · 일반 · 베이스: 잎사귀 용
- 성격: 처음 만나는 친구. 뭐든 신기해한다
- 외형: 연두 몸에 크림 배, 머리 위 잎 뭉치, 등과 몸의 잎맥 반점, 꼬리 끝에 작은 잎
- 표정: 크고 둥근 눈, 살짝 벌린 입("신기해!")
- 시그니처: 꼬리 잎을 톡 피우고 고개를 갸웃한다

**다리뛰기 `bridge_hopper`** · 희귀 · 베이스: 길잡이 용 · *조정 필요(2-2절)*
- 성격: 깡총깡총 활발하다. 다리와 건너기를 좋아한다
- 외형: Sage 몸에 크림 배, 둥근 돌기 3개와 작은 박쥐 날개, 등에 다리 아치 무늬 3개, 꼬리에 흰 차선 점선, 목에 Peach 스카프(희귀 액세서리)
- 표정: 한쪽 눈 찡긋, 활짝 웃는 입

**산정령 `mountain_sprite`** · 초희귀 · 베이스: 바위 용 · *조정 필요(2-2절)*
- 성격: 차분하고 의젓한 형·누나 느낌
- 외형: 스톤 그레이 몸에 이끼 초록 반점, 둥글고 뭉툭한 바위 뿔과 등 장식, 꼬리 끝에 은은히 빛나는 이끼 결정, 몸에 펄감(초희귀)

#### water — Sky 계열 · 비와 물

**웅덩이삐약 `puddle_pip`** · 일반 · 베이스: 비의 용
- 성격: 아기 새처럼 물웅덩이에서 첨벙댄다
- 외형: 머리 위 물방울 하나, 파란 몸에 물방울 반점, 꼬리 끝 물방울
- 표정: 동그란 눈, 작게 벌린 입
- 시그니처: 발밑 웅덩이에서 첨벙, 물방울이 튀어 오른다

**강미끄럼 `river_glider`** · 희귀 · 베이스: 여울 용
- 성격: 느긋하게 흘러가는 성격
- 외형: 하늘색~파랑 몸에 물결 반점, 물방울 모양 뿔과 귀 지느러미, 몸보다 긴 지느러미형 꼬리
- 표정: 살짝 처진 눈, 편안한 미소
- 시그니처: 꼬리 끝에서 물방울을 만들어 공중에 띄운다

**물결지기 `tide_keeper`** · 초희귀 · 베이스: 파도 용 (**시연 종**)
- 성격: 잔잔하고 든든한 바다 지킴이
- 외형: Sky 반투명 몸에 물방울 광택, 파도 모양 반투명 날개, 머리에 조개 장식, 꼬리 끝에 빛나는 진주(초희귀)

- 시그니처: 조개를 열어 작은 진주를 보여 준다

#### dark — Lavender 계열 · 밤에 켜지는 작은 빛

dark는 무섭다는 뜻이 아니다. **밤에 켜지는 작은 빛**을 주제로 한다.

**등불나방 `lamp_moth`** · 일반 · 베이스: 불빛 용
- 성격: 불빛만 보면 신난다
- 외형: 보라 몸, 뿔 대신 더듬이 2개와 끝의 작은 구슬 전구, 나방처럼 둥글게 빛나는 날개
- 표정: 반짝이는 눈, "반짝!" 하고 벌린 입
- 시그니처: 더듬이 전구가 차례로 켜진다

**터널나방 `tunnel_moth`** · 희귀 · 베이스: 불빛 용과 길잡이 용
- 성격: 어둠 속 길잡이. 든든하다
- 외형: 라벤더 몸, 구슬 뿔 3개(등불나방의 더듬이와 구분), 날개와 몸옆에 터널 조명처럼 줄지은 창 무늬, 꼬리 끝에 랜턴
- 표정: 집중한 눈, 자신 있는 미소
- 시그니처: 몸의 창이 앞에서 뒤로 하나씩 켜진다

**별부엉이 `star_owl`** · 초희귀 · 베이스: 별빛 용
- 성격: 똑똑한 밤하늘 박사
- 외형: 남색 몸, 부엉이 귀깃 같은 뿔, 초승달 꼬리 장식, 몸의 별 무늬와 날개가 은은하게 빛난다(초희귀)
- 표정: 크고 동그란 눈, "후후" 하는 작은 입
- 시그니처: 고개를 기울여 초승달과 별 무늬를 보여 준다

#### 특별 — 두 환경이 겹친 날

**폭풍등 `storm_lantern`** · rain + tunnel
- 성격: 씩씩한 등불. 비 오는 터널에서 태어났다
- 외형: water의 Sky 몸에 빗방울 크리스탈 왕관, 랜턴 꼬리, 반투명 날개
- 표정: 씩씩하게 올라간 눈썹, 크게 웃는 입("번쩍!")
- 시그니처: 랜턴이 번쩍 켜지며 빗방울이 빛으로 바뀐다

**고속혜성 `highway_comet`** · highway + night
- 성격: 빠른 게 좋은 신나는 혜성
- 외형: 별부엉이보다 밝은 라벤더 보라 몸, 차선 점선 무늬, 혜성 꼬리(빛의 띠), 머리 위 별 하나
- 표정: 신나서 반쯤 감은 눈, 활짝 웃는 입("슝!")
- 시그니처: 빛의 띠를 남기고 한 바퀴 돌아 제자리로 돌아온다. 화면 밖으로 나가지 않는다

**바다안개 `sea_mist`** · coast + rain
- 성격: 몽글몽글 조용한 안개
- 외형: 크림과 Sky의 구름 같은 몸, 머리와 꼬리의 둥근 구름 뭉치, 작은 조개 장식, 몸 주변을 떠도는 안개
- 표정: 반쯤 감은 나른한 눈, 작은 미소
- 시그니처: 안개 뭉치를 만들어 그 위에 올라가 둥실 떠다닌다

## 6. 등급별 시각 규칙

색만 바꾸지 않는다. 등급이 오를수록 **표현 밀도**가 올라간다.

| 표시 등급 | 실루엣·장식 | 재질 | 이펙트 | 부화 연출 |
| --- | --- | --- | --- | --- |
| 일반 | 기본 체형 + 속성 장식 1개 | 매트 | 없음 | 기본 (약 2초) |
| 희귀 | + 고유 무늬 또는 액세서리 | 매트 | Happy 때 작은 파티클 | + 파티클 |
| 초희귀 | + 꼬리 끝 빛나는 장식, 반투명 날개 | 펄감 | Idle 중 반짝임 | + 빛 기둥 |
| 특별 | 두 속성 재료 조합 | 반투명 + 은은한 발광 | (선택) 오라 링 | 전용 등장 (4초 이내) |

> **회의에서 정할 것:** 레퍼런스 시트의 특별 3종에는 오라 링이 없고 반투명·발광만 있다. 링을 꼭 넣을지 정한다.

## 7. 알

schema 기준 알은 크기 3종(`eggTier`: small / mid / large)이고, 종은 부화할 때 정해진다. 그래서 알은 처음에 무늬가 없고, **품는 동안 지나간 환경이 표면에 무늬로 떠오른다.** 알은 폰이 자동으로 지급한다. 아이가 고르지 않는다.

| 자산 | 내용 |
| --- | --- |
| 기본 알 | 크림색 민무늬. 크기 3종 × 성장 3단계(1 민무늬 / 2 광택 증가 / 3 금과 빛) = 9장 |
| 환경 무늬 | 7종 투명 레이어. 기본 알 윤곽에 맞춰 겹친다 |

| 태그 | 무늬 | 라벨 |
| --- | --- | --- |
| `rain` | 물방울과 빗줄기 | 비 |
| `night` | 별과 초승달 | 밤 |
| `tunnel` | 줄지은 작은 불빛 | 터널 |
| `highway` | 차선 점선과 도로 띠 | 고속도로 |
| `coast` | 파도와 조개 | 해안 |
| `mountain` | 산봉우리 | 산 |
| `city` | 창문이 있는 빌딩 | 도심 |

무늬는 표시 연출일 뿐이며 판정에 쓰지 않는다. 품기 화면에서는 무늬와 함께 **환경 칩(아이콘 + 글자)**을 보여 준다 (원칙 2).

> **B 확인 필요:** 무늬 레이어(`egg/pattern_{tag}.png`)를 겹쳐 그릴지. 넣지 않으면 기본 알 9장만 쓴다.
> **B·C 확인 필요:** 현재 폰 코드는 알 크기를 small로 고정한다(`pairing_screen.dart:79`). 크기를 쓰지 않으면 기본 알은 1종 × 3단계로 줄인다.

## 11. 앱 아이콘

SVG 시안: [`art/design/icon/`](../art/design/icon/). 글자 "ALLO"만 쓴다. 캐릭터처럼 통통한 점토 글자이고, 마지막 O는 **알**이다(알로 = 알 + 길). 글꼴이 아니라 둥근 선으로 그려서 어느 기기에서도 모양이 같다.

| 파일 | 시안 | 쓰는 곳 |
| --- | --- | --- |
| `allo-icon-a.svg` | **A 점토 파스텔 (추천)** — 크림 바탕, 글자마다 속성 색(A 땅 · L 물 · L 밤), 노란 알 O에 눈과 볼 | 폰·차 공통 |
| `allo-icon-b.svg` | B 하늘 길 — 하늘 바탕 흰 글자, 알 위 새싹, 아래 차선 | 대안 |
| `allo-icon-c.svg` | C 밤 드라이브 — 남색 바탕 버터 글자, 빛나는 알 | 다크 모드 후보. 차 런처(남색)에선 경계가 약함 |
| `allo-icon-d.svg` | D 2줄 (AL / LO) | 48px 이하, 알림 아이콘 |
| `*-full.svg` | 마스크 없는 정사각 | iOS 1024px(불투명), 스토어 |
| `*-adaptive-fg.svg` | Android adaptive 전경(투명). 내용을 안전 영역(108dp 중 지름 66dp)에 맞춤 | 배경 색은 `#FFF0D8` |

- 한 줄 ALLO는 48px 이하에서 뭉개진다 → 작은 크기는 D
- 차량 앱은 지금 manifest에 아이콘이 없다(`car/app/src/main/AndroidManifest.xml`) → A가 등록. 폰은 B가 적용
- 최종 PNG는 SVG를 그대로 내보내거나, 캐릭터 레퍼런스와 같은 점토 질감으로 다시 렌더링한다
