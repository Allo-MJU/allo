## 3. 담당 경계

```
[차량 앱 · A] --신호--> [Firebase · C가 스키마] --상태--> [폰 앱 · B]
                                                            ^
                                              [게임 로직 · C] |
                                              [아트 · D] ------
```

- A와 B는 **직접 통신하지 않습니다.** 모든 교환은 Firebase 스키마를 통해서만
- C는 스키마의 주인이며, 양쪽의 중재자입니다
- D의 아트는 B가 통합합니다. 에셋 네이밍 규칙을 Day 1에 합의

## 4. 인터페이스 계약 — Day 1에 고정

**이게 정해지면 네 명이 완전히 병렬로 갑니다.** A·C가 11/3 오전에 확정하고 전원 공유.

```
/sessions/{sessionId}
  pairedAt: timestamp
  vehicle:
    gear: "P" | "D" | "R" | "N"
    speedKph: number
    harshBrakeCount: number        # 누적
    harshSteerCount: number        # 누적
    distanceM: number              # 누적 주행거리
    wiperLevel: 0 | 1 | 2 | 3
    headlightOn: boolean
    seatRow2Occupied: boolean
    etaSeconds: number | null      # 내비 미사용 시 null
    envTags: ["rain" | "tunnel" | "highway" | "coast" | ...]
  game:
    eggTier: "small" | "mid" | "large"
    stage: "incubating" | "hatched"
    progress: 0..1
    speciesId: string | null
```

**원칙**

- 위치 좌표는 올리지 않습니다. 차량 앱이 `envTags`로 변환해서 보냅니다 (아동 개인정보 요건)
- 전송 주기 1초. 변화 없으면 생략
- `etaSeconds`가 null이면 폰 앱은 `distanceM` 기준 폴백으로 전환
