# 창밖 이야기 Unity 적용 기록

2026-11-13. Unity 차 안 화면에 8개 환경의 한국어 버튼 이야기를 추가했다. 차량 판정은 기존 WindowScene/SceneStabilizer를 공유하고 이야기 진행·카드는 Dart가 로컬에서 관리한다.

## 적용 내용

- 지속되는 StoryOverlay: 주제 초대, 대사와 두 선택, 8종 2D 실험, 동행 친구 초상, 여행 노트·발견 카드.
- 이야기/노트 중 하단 돌봄 도크를 교체하고 알 상태는 유지한다. 차 안 사물 탭·알 조작·카메라 입력과 일반 말풍선은 이야기와 동시 실행되지 않는다.
- 사진·부화·돌봄 종료·남은 시간 임계점·화면 이동·백그라운드는 이야기를 보관한다. 저장 중에도 돌봄 복귀는 가능하다.
- 단계 토큰과 요청 ID를 검증하며 이야기 선택은 전역 게임 busy나 친밀도·재료에 영향을 주지 않는다.
- 8편 모두 정적 대본 기반이다. 실시간 AI 생성은 추가하지 않았다. 후속 로컬 음성 연결은 [TTS 매칭 기록](window-story-tts-matching.md)을 참고한다. 콘텐츠 메타데이터는 검수 전 초안 상태를 유지한다.

- 여행 노트 진입을 기존 돌봄 하단 행의 여섯 번째 버튼으로 통합. 공용 버튼 생성기로 높이54·글자21·색상·간격 통일, 행 폭1020으로 조정. 알 선택 화면에서는 시작 버튼 옆 배치.
- 상단 독립 여행 노트 버튼 제거, 노트 닫기는 노트 아래 하단에 배치.
- Unity EditMode149 통과, Android 내보내기·APK 빌드 성공. 800×360에서6버튼 정렬 및 노트 열기/닫기 확인. 캡처 `27-care-small.png`, `28-note-close-small.png`, `29-closed-small.png`, `30-bottom-final.png`.
- 에뮬레이터 설치 공간 제한은 앱 데이터 보존 재설치 및 임시 저장소 임계값 조정으로 해결. 임계값과 화면 해상도 원복 확인.

## 이야기 초대 하단 정렬 보완

- 상단 이야기 초대 UI 제거. 여행 노트 옆에 공용 버튼으로 이어 하기 또는 이야기 시작/나중에 표시. 돌봄 하단 행 폭을 표시 항목 수에 맞춰 조정. 알 선택 화면도 같은 하단 동작 행 사용.
- Unity149 통과, Android export/APK 빌드 성공. 800×360에서 알 선택·돌봄 하단 이어 하기 정렬, 버튼을 눌러 보관된 이야기 재개 확인. 화면32–35 저장. 에뮬레이터 해상도·임시 설치 임계값 원복.
