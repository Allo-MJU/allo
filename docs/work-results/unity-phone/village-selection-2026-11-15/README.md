# 마을 표시 친구 선택 화면

2026-11-15 실제 Unity PlayMode UGUI를 1600×720, 1024×576로 렌더링한 화면이다. 실제 소유 데이터가 아닌 6개체 AppState fixture를 입력했다. 설치 APK·실제 차량·폰 저장 성공을 촬영한 증거는 아니다.

- `map-*`: 첫 네 마리가 아니라 fixture에서 선택한 길싹이·등불나방·바다안개·폭풍등만 표시한다.
- `selector-*`: 같은 실제 선택 UI의 4/4 상태다. 선택을 해제하면 다른 개체를 고를 수 있고, 저장은 호스트 확인을 기다린다.
- 기존 숲 마을·시설·캐릭터 그림과 글꼴을 그대로 사용한다. 임시 캡처용 Editor 스크립트는 촬영 후 제거했다.

Unity EditMode의 선택/취소/저장 실패/뒤로 가기 및 Flutter의 저장·복원·개체 검증·프로필 분리 검증은 `docs/verification/2026-11-15-collection-village.md`를 따른다.
