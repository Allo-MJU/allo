# 시설 캐릭터 이동·확대 상세 — 2026-11-14

사용자가 승인한 지도 배경 위 확대 상세 방식으로 반영했다. 작업 위치는 `companion-learning-latest/allo`, 기준 커밋은 `99309e9`이며 다른 채팅의 미커밋 변경은 보존했다.

- 홈/시설의 소유 캐릭터는 원래 위치 주변에서 느리게 이동한다. 스냅샷 갱신은 위치를 초기화하지 않는다. 움직임 줄이기, 상세/확인창, 드래그, 처리 중에는 이동을 멈춘다.
- 캐릭터 탭은 해당 소유 ID의 확대 그림과 이름·역할·설명·배운 행동·요리 주기를 표시한다. 도감으로 이동하지 않는다. 닫기와 시스템 뒤로가기로 지도에 복귀한다.
- 기존 친구 메뉴는 도감으로 표시한다. 기존 도감과 차량 동행 선택 기능은 유지한다.
- 캐릭터 삭제 후 빈 자리 재사용, 선택 삭제 시 확인창 무효화, 요리 확인창의 뒤로가기 순서, 시설/개체 상세 스크롤 분리를 검증했다.

## 검증

Unity 6000.0.85f2에서 EditMode 202개와 PlayMode 시설 입력 테스트 2개를 통과했다. 최초 기능 테스트 실패와 리뷰 지적 5건의 재현 실패를 확인한 뒤 수정했다. 변경 파일의 `git diff --check`도 통과했다.

아래 PNG는 실제 수정한 UGUI를 Unity PlayMode에서 1600×720 렌더 텍스처로 캡처한 결과다. 테스트는 같은 종의 서로 다른 두 소유 개체를 사용해 정확한 개체 선택도 검증한다. 기기에 설치된 APK를 캡처한 결과는 아니다.

- [시설 지도](village.png)
- [개체 확대 상세](village-character-detail.png)

앱 재빌드·재설치, 커밋·푸시는 하지 않았다. 다른 채팅과 같은 작업 폴더에서 추가 작업 중이므로 해당 변경들을 일괄 커밋하지 않았다.

## 변경 범위

- `AppUiMap.cs`: 마커 배치/탭, 기존 프레임 갱신 연결.
- `AppUiVillageCharacter.cs`: 배회, 선택 수명, 확대 상세와 기존 행동/요리 UI 재사용.
- `AppUi.cs`: 상태 변경 시 선택 검증 1줄, 친구→도감 문구 1줄. 나머지 기존 diff는 다른 작업 소유다.
- `FlutterBridge.cs`: 시스템 뒤로가기의 로컬 상세/확인창 닫기 우선 처리 2줄.
- `AppVillageCharacterTests.cs`, `AppVillagePanTests.cs`, `AppVillageInputTests.cs`: 상태·입력 회귀와 렌더 캡처.
