# 친구 부탁 실제 UI 캡처

2026-11-15 Unity PlayMode의 실제 UGUI를 1600×720/1024×576로 렌더링했다. 6개체와 음식/이야기/여행 부탁의 synthetic AppState를 입력했으며, 실제 앱 설치·DB 저장·운전자 시연을 촬영한 증거는 아니다.

- `marker-*`: 마을의 선택 친구 옆에 작은? 표시.
- `unread-*`: 캐릭터 상세를 열어도 본문은 숨겨지고?만 표시.
- `food-*`: 명시적으로?를 눌러 부탁·조건·함께하기/나중에를 확인.
- `story-*`: 수락한 이야기 관찰 부탁과 직접 확인 행동.
- `travel-*`: 장소를 고르는 부탁; 보호자 확인과 도착 검증은 별도다.
- `unity-open-intent.json`: Unity가 실제 JsonUtility로 직렬화한 synthetic openQuest 요청이다. 생략한 placeId가 빈 문자열로 나와 Dart에서 이를 선택적 값으로 처리하는 회귀를 확인했다.

화면을 보고 작은 크기에서도 제목·조건·행동이 보이며, 긴 상세는 기존 스크롤을 사용하는 것을 확인했다. 임시 촬영 Editor 스크립트는 제거했다. 실제 저장과 주기/완료 판정은 별도 테스트 및 검증 기록을 따른다.
