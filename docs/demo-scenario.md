# 시연 시나리오 — 비 오는 날 고속도로 (9단계)

영상 2~3분. 에뮬레이터(차) + 폰 에뮬레이터 또는 실기기 화면을 나란히 녹화한다.
명령은 `scripts/vc.sh` 함수 기준. 하트비트는 스크립트가 처리한다.

| # | 장면 | 차 화면 | 폰 화면 | 명령 |
| --- | --- | --- | --- | --- |
| 1 | 아이가 뒷자리 탑승 | 페어링 QR + 6자리 | (알림) | `seat rear_right true` |
| 2 | QR 페어링 | "연결됨" | 알 고르기 → 품기 | 폰에서 QR 스캔 또는 코드 입력 |
| 3 | 출발, 와이퍼 작동 | "알이 자라는 중 · 5%" 한 줄 | 알 + 빗방울, `rain` 칩 | `wiper 2` · `gear Drive` · `drive 60 30 0 0` |
| 4 | 급제동 → 알 흔들림 → 감싸기 | 진행바 | 알 흔들림, "감싸기" 탭 | `drive 30 0 80 0` 1초 |
| 5 | **휴게소 정차 → 차 화면에 아이 화면** | 게임 상태 렌더 (진행도·케어 횟수) | 품기 계속 | `drive 0 0 20 0` → `gear Park` |
| 6 | 다시 출발 → 부화! | 주행 모드 한 줄 → (정차 시) 부화 연출 | 금 가기 → 빛 → **Tide Keeper** | `gear Drive` · `drive 90 25 0 0` 유지 |
| 7 | Gleo 음성 | *"물 속성 아이가 깨어났어요! 뒷자리에 물어보세요."* | 동행 화면 | 폰 `hatched` 이벤트 → 차량 앱 TTS |
| 8 | 창밖 보기 → 영어 단어 | — | "저기 봐! 산이야 · mountain" → "봤어!" | 폰 조작 |
| 9 | 도착 → 도감 등록 | 정차 화면 → 도감 요약 | 도감 칸 채워짐 (날짜·rain·tier 3) | `gear Park` → 폰 "도착" |

## 시간 압축

- 실제 50km 알을 영상 안에서 부화시키려면 `scripts/scenario_rainy_highway.sh` 의 주행 시간 동안 폰 앱이 받는 `distanceM` 이 25km 를 넘어야 한다. 에뮬레이터 Odometer 가 그만큼 안 움직이면 **시연 빌드에서 `HatchTimer` 목표 거리를 1/100 로 줄이는 `--dart-define=DEMO_SCALE=100`** 을 둔다 (TODO B/C)
- 또는 `FEED=fake` 로 폰 단독 녹화 후 차 화면과 편집으로 합친다. 통합이 불안정할 때의 보험

## 녹화 메모 (SoftRide 선례)

- 에뮬레이터는 `-gpu host -no-snapshot` 으로 cold boot
- 에뮬레이터 소리는 매우 작다. 편집 때 증폭
- Virtual Console 명령 시각을 로그로 남겨 자막 타이밍에 쓴다
