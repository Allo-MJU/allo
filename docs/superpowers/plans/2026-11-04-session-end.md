# 차량 종료 처리 구현 기록

차량의 `sessionEnd`를 받은 폰은 종료된 세션에서 새 품기를 막고, 서버의 마지막 차량 상태를 읽어 진행·도감을 저장한다. 저장 실패 시 종료 화면에서 재시도하며, 완료 후 새 차량 연결이나 도감으로 이동한다.

- 구현 및 검증 절차: [폰 README](../../../phone/README.md#종료된-차량-세션)
- 차량·폰 공통 계약: [C 확정본 PR #38](https://github.com/Allo-MJU/allo/pull/38)
- 구현 PR: [#25](https://github.com/Allo-MJU/allo/pull/25)
- 차량 송신 보강: [#27](https://github.com/Allo-MJU/allo/pull/27)

중복 종료는 같은 저장 작업을 공유한다. 이전 연결의 늦은 응답은 현재 세션에 적용하지 않는다. 종료 저장이 완료되기 전에는 새 연결로 이동하지 않는다.

자동 검증은 폰의 종료·저장 실패·중복 이벤트·최종 스냅샷·Fake 재시작 회귀를 포함한다. 실제 Firebase·차량 통합 테스트는 팀원의 별도 검증 범위다.
