# 차량 아이템 던지기와 직접 돌봄

사용자가 제공한 가로 게임의 원형 버튼 모음을 배치 참고로 사용한다. 게임 이미지나 캐릭터 자산은 복사하지 않는다. 이전 단일 행동 메뉴는 이번 요청으로 대체한다.

## 화면과 입력

- 기존 `차 안에서 함께하기` 상단 제목 자리에 `차량 QR 연결하기` 버튼을 둔다. 미연결 상태도 이 위치에서 연결 화면에 진입한다.
- 오른쪽 탭 이동은 유지하고 왼쪽에 간식·물·공·인형 원형 버튼을 배치한다. 선택한 물건은 이전 행동 버튼 자리인 하단 중앙에 나타난다.
- 하단 물건을 위·좌우·대각선으로 스와이프하면 손가락 방향과 세기에 맞춰 포물선으로 날아간다. 아래로 당기는 동작은 취소한다. 선택 자체는 돌봄을 실행하지 않는다. 기존 승인된 commonCare 경로를 사용하며 새로운 보상 규칙을 만들지 않는다.
- 캐릭터 한 번 탭은 대화, 왕복 문지르기는 쓰다듬기, 더블 탭 후 끌기는 자유 이동이다. 첫 탭의 대화는 짧은 더블 탭 판정 시간이 지난 뒤 실행해 겹침을 막는다. 캐릭터는 유효한 차량 내 표면의 원하는 자리에 내려놓을 수 있다. 쿠션·담요는 고정 위치에 두고 그곳에 내려놓으면 쉬기/덮기 반응을 실행한다.
- 알의 기존 직접 문지르기·자리 이동·친밀도·사진·부화 규칙은 보존한다. 버튼 메뉴 제거로 말하기/사진 등 기존 알 기능에 접근하지 못하는 일이 없어야 한다.
- 화면 이동·배경 전환·프로필/대상/여행 변경·모달 상태에서는 진행 중 입력/던지기를 취소한다. 정상 스냅샷 갱신은 입력을 끊지 않는다.

## 구현 결정

기존 Unity Toys와 CritterDirector를 확장한다. 새 외부 라이브러리나 서버 API는 필요하지 않다. 원형 UI는 AppUi가, 입력·투사체·고정 휴식 소품은 CabinInteraction이 담당한다. 게임 보상과 소유 상태는 기존 Dart 호스트가 승인한다. AI 대화의 서버 책임은 그대로 유지한다.

상시 전체 행동 바와 메뉴 방식은 사용자가 명시적으로 대체했다. 원형 버튼+직접 조작이 이번 구현 방향이며 아이템을 누르자마자 행동을 실행하는 방식은 던지기 요구를 충족하지 않는다.
