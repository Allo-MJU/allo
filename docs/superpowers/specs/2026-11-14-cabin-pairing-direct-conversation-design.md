# 차량 연결 진입과 직접 대화

2026-11-14 사용자 후속 지시. 기존 `feat/trip-egg-companion-interaction` 코드와 승인된 마을 상세 변경이 함께 있는 `4d1374b`를 기준으로 한다. 같은 브랜치에 이미 앞선 코드가 있어 가짜 merge commit을 만들지 않고 결합 상태를 검증했다(Unity202통과).

## 요구와 적용 범위

- 최초 미연결 차 안은 빈 차량과 주행 배경, 하단 ‘차량 연결하기’ 버튼 하나만 표시한다. 알/친구/여행 노트/이야기 시작·이어하기를 자동 표시하지 않는다.
- 연결 버튼은 페어링 화면으로 이동한다. 실제 차량 QR 스캔과 기존 세션 ID+코드 직접 입력을 제공한다. QR 취소/실패는 지급하지 않는다.
- 성공한 페어링만 자동 알 준비를 일으킨다. fake 초기화에서 자동 연결/알 지급을 하지 않는다. 유효한 기존 연결 복구와 미부화 알 이어하기는 보존한다.
- 여행당 한 알, 같은 여행 재접속/재시작 중복 차단, 미부화 알 승계, 기존 호감도·사진·부화 시간/거리 규칙은 유지한다.
- 기존 친구는 친구/도감 상세의 ‘차 안으로 데리고 오기’로 불러온다. 기존 실제 소유 검증·연결 조건을 유지하고 선택하지 않은 보유 친구가 차 안에 자동 등장하지 않는다.
- 알과 친구는 독립이다. 친구가 있거나 대화 중이어도 알 상태·호감도·사진·자리·시간/거리 진행을 숨기거나 바꾸지 않는다. 친구 놀이가 알 보상을 중복 발생시키지 않는다.
- 캐릭터를 클릭하면 메뉴 선택 없이 바로 대화를 연다. ‘이야기 듣기/말 걸기’ 두 모드와 다음 이야기/반복 읽기 UI를 제거한다.
- 대화는 캐릭터의 인사와 아이 입력/응답을 이어가는 방식이다. 짧은 서버 응답 말풍선과 입력/전송·마이크를 사용하고, 고정된 이야기 문단을 다음 버튼으로 넘기는 화면으로 구현하지 않는다.
- 같은 친구의 대화 화면을 잠깐 닫고 다시 열 때 현재 메모리 대화 문맥을 이어간다. 대상·프로필·연결 변경 때 구분하고 원문은 영구 저장하지 않는다.

## 서버/앱 책임

서버가 페르소나·고정된 캐릭터 배경·학습 자료·현재 세션 대화 문맥으로 자연스러운 인사/답변을 생성한다. 정해진 사건/설정을 임의로 바꾸지는 않지만 그 이야기를 순서대로 낭독하도록 강제하지 않는다. 10세 수준, 가끔 영어/역사/상식 연결, 선택적인 부모님 제안이라는 기존 원칙을 유지한다.

새 직접 인사 `greet`와 기존 `chat` turn은 AI 백엔드가 처리한다. 앱은 입력·표시·TTS와 요청 수명만 관리한다. 앱에 본문/페르소나를 다시 넣지 않는다. 키 미설정/서버 실패는 연결 오류로 표시하고 고정 문단을 대화인 것처럼 대신 내보내지 않는다. 기존 invite/listen/next/repeat API는 구버전 호환용으로 남을 수 있으나 새 차 안 UI가 호출하지 않는다.

## 페어링·표시 판단

‘처음’은 유효한 연결이 없는 상태다. 정상 진행 중인 기존 연결/알을 화면 진입 때 삭제하거나 새로 지급하지 않는다. 최초 미연결 앱과 명시적으로 연결을 끊은 차 안에서는 알/친구를 감추고 연결 버튼만 보인다. 다시 페어링하면 기존 여행/알 정책대로 복구한다.

‘차량 연결하기’는 별도 pairing view로 이동하며, QR은 이미 설치된 Flutter MobileScanner 화면을 재사용한다. Unity를 잠시 뒤로 보내 Flutter 스캐너를 보여주고, 결과/취소 후 Unity를 복귀시킨다. 별도 카메라 라이브러리·두 번째 Flutter 엔진·새 계정 체계는 추가하지 않는다.

창밖 실험과 노트 데이터/순수 모듈은 삭제하지 않되 새 차 안 화면에서 자동 초대·노트·이야기 버튼·오버레이를 띄우지 않는다. 오래된 실험 상태가 직접 대화나 알 입력을 차단하지 않도록 표시/입력 소유권을 정리한다.

## 검증

미연결 empty/cast 없음/버튼1개, 연결 버튼→pairing view, QR 취소·인식 성공·직접 입력, 중복 QR/동일 여행 이어하기, fake 초기화 무지급, 친구 소환 전후 알 상태/보상/타이머 유지, 실제 캐릭터 클릭→직접 chat, 선택 메뉴/next UI 없음, 인사·질문·후속 질문의 서버 persona/context, 서버 실패의 정직한 UI, close/reopen 문맥, native QR/STT 복귀·늦은 결과, 기존 마을 상세/도감/낚시 유지.

## 행동 UI 후속 요청

상시 표시되는 알/친구 행동 바를 제거한다. 연결된 차 안에 유효한 대상이 있으면 하단 ‘행동’ pill 하나를 표시하고, 눌렀을 때만 선택 시트가 열린다. 최초 미연결 차 안의 연결 버튼 하나 규칙은 바꾸지 않는다.

선택 시트는 아이폰 액션 시트 느낌의 둥근 면·절제된 반투명/경계·부드러운 눌림·기존 한글 폰트를 사용한다. 새 이미지·전용 폰트·라이브러리를 추가하지 않는다. 알 돌보기와 친구와 놀기를 그룹으로 구분하며, 기존 알 호감도/사진/자리/말 입력과 친구 7종 놀이는 원래 대상을 유지한다. 밖을 누르거나 닫기로 닫히고, 메뉴를 열 때 대화 presentation만 닫아 같은 친구의 메모리 문맥은 보존한다. 메뉴 자체가 learningUiBlocked를 켜 선택지까지 비활성화하는 구조를 만들지 않는다. 대상/연결/화면/알 종료 변경 시 stale 시트를 정리하며 기존 숨은 drawer 회귀 수정을 유지한다.
