# 알 돌보기 종료 이후 안내 — 제안

2026-11-15. 사용자 요청의 4번 구체화. **제안 전용이며 이 문서의 실패/종료 화면은 아직 구현하지 않는다.**

## 해결할 장면

첫 여행에서 알이 실패하거나 사용자가 돌보기를 그만두면, 알과 HUD가 사라져 빈 차량 화면만 남을 수 있다. 여행당 한 알 규칙을 유지하면서 ‘무슨 일이 일어났고 지금 무엇을 할 수 있는지’를 알려 준다. 아이에게 잘못이나 손실을 강조하지 않는다.

## 제안 화면

기존 차 안 3D 화면과 카메라를 유지한다. 알 HUD가 있던 왼쪽 위 자리에 작은 안내 패널 하나를 표시한다. 배경을 가리는 전체 화면 팝업·자동 화면 이동·자동 음성은 쓰지 않는다.

### A. 제한시간 종료

제목: `이번 알 돌보기가 끝났어요`

설명: `다음 여행에서 새 알을 만날 수 있어요.`

- 기존 친구가 있으면 주 행동 `친구 데려오기` → 기존 도감으로 이동. 고른 정확한 개체의 기존 동행 기능을 재사용한다.
- 기존 친구가 없으면 주 행동 `마을 둘러보기` → 기존 마을로 이동한다.
- 보조 행동 `차 안에 머무르기` → 패널을 작게 접는다. 상단의 `돌보기 안내`로 다시 열 수 있다.

`실패했어요`, `도망갔어요`, `친밀도가 부족해요`처럼 아이를 평가하는 문구나 이번 여행에 불가능한 `새 알 받기` 버튼은 넣지 않는다. 다음 여행에 돌아오는 것은 실패한 같은 알이 아니라 새 알임을 문구에서 구분한다.

### B. 사용자가 돌보기 그만두기 선택

기존 확인창에서 종료하면 제목 `알 돌보기를 마쳤어요`, 설명 `이미 만난 친구들은 그대로 있어요. 새 알은 다음 여행에서 만나요.`를 보여 준다. 이후 행동은 A와 같다. 종료 취소는 기존 확인창에서 처리한다.

### C. 여행이 먼저 끝나 미부화 알을 이어 키울 수 있음

제목: `알은 다음 여행에도 함께해요`

설명: `지금까지 돌본 만큼 저장했어요. 다음 여행에서 이어서 키워요.`

- 저장이 실제 성공한 경우에만 이 문구를 쓴다.
- 저장 대기에는 `돌본 내용을 저장하고 있어요`, 저장 실패에는 `아직 저장하지 못했어요`와 기존 저장 재시도 행동을 제공한다.
- 주 행동 `마을로 가기`; 새 여행 연결 시 기존 알이 복원됐다는 짧은 안내를 한 번 보여 준다.

실패/버리기는 C로 표현하지 않는다. 현재 종료·체크포인트 계약을 그대로 따른다.

### D. 12종 수집 완료 후 새 여행

제목: `모든 친구를 만났어요!`

설명: `이번 여행 선물로 베리 간식 3개를 받았어요.`

- 보상 receipt와 재고 저장이 성공한 뒤에만 표시한다.
- 주 행동 `친구 데려오기`, 보조 행동 `간식 확인` → 기존 가방의 음식 탭.
- 같은 여행 재접속은 선물을 다시 주지 않는다. `이번 여행의 간식은 가방에 있어요`로 표시한다.

이 D 상태의 간식 지급 자체는 이번 확정 구현 범위다. A~C 안내 디자인과 펼침/접힘 상호작용은 사용자 선택 전까지 제안으로 남긴다.

## 다음 단계 안내도 같은 규칙 사용

첫 진입의 마을에는 안내 한 줄만 둔다: `차량과 연결해 첫 알을 만나 보세요` + `차량 연결하기`. 첫 친구를 얻으면 `새 친구를 마을에 불러 볼까요?` + 기존 마을 친구 선택 행동으로 바꾼다. 모든 기능을 설명하는 긴 튜토리얼은 추가하지 않는다.

## 검증할 조건

첫 알 실패/명시 종료/미부화 정상 종료/저장 실패/수집 완료를 서로 오인하지 않는다. 친구0명·1명 이상에서 가능한 행동만 표시한다. 홈/차 안 이동·스냅샷 갱신 때 안내를 반복해 열지 않는다. 대화·드래그·사진 화면 위로 안내가 끼어들지 않게 한다. 선택/계정 전환 시 다른 여행의 안내를 보여 주지 않는다.
