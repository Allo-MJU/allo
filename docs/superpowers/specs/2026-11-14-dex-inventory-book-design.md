# 도감·가방 책 UI 개편안

상태: 2026-11-14 사용자가 “ㄱㄱ”로 승인. 별도 작업본에서 구현.

## 요청과 적용 범위

사용자가 제공한 게임 도감 이미지를 구성 참고로 삼아, ALLO 폰 Unity 앱의 도감과 가방을 전면 교체한다. 기존 데모의 패널·카드 디자인은 시각적 기준으로 유지하지 않는다. 펼친 책을 배경으로 왼쪽에 선택 항목의 상세, 오른쪽에 캐릭터 얼굴 또는 아이템 목록을 둔다.

이미지 속 게임 이름·몬스터·설명·보상·필터는 참고 게임의 콘텐츠이며 ALLO 요구사항으로 옮기지 않는다.

## 구성 선택

요청에서 이미 펼친 책과 좌우 위치를 지정했다. 따라서 가로 화면에서 책 한 권을 보여 주는 구성을 기본안으로 한다. 별도 상세 팝업이나 세로 카드 목록은 요청한 좌우 탐색 흐름에 맞지 않아 채택하지 않는다.

- 책: 따뜻한 미색 종이, 짙은 갈색 표지 가장자리, 중앙 책등과 얇은 페이지 층. 배경 장식은 내용의 대비를 방해하지 않을 정도로 제한한다.
- 왼쪽 약 45%: 선택한 캐릭터·아이템의 큰 그림과 상세 정보, 가능한 행동.
- 오른쪽 약 55%: 얼굴·아이템 중심의 작은 슬롯, 짧은 이름, 필요한 수량 표시. 선택 슬롯은 금색 테두리와 모서리 표시로 식별한다.
- 공통 책갈피: 도감·가방을 오갈 수 있는 탭. 가방에서는 재료·요리를 나눈다.
- 현재 전역 HUD와 다른 화면의 내비게이션은 유지하고, 책은 도감·가방 콘텐츠 영역을 채운다.

위 비율·색상·탭 형태는 구현자가 제안한 값이며 사용자 확정값이 아니다.

## 도감

오른쪽에는 얼굴이 중심이 되는 초상 슬롯을 둔다. 실사용 스프라이트에서 얼굴이 잘리지 않는지 종별로 확인하고, 얼굴 전용 자산이 없다는 이유로 전신 이미지를 작은 슬롯에 그대로 축소해 끝내지 않는다. 왼쪽 상세에는 기존 전신 스프라이트를 크게 보여 준다.

이름, 속성, 역할, 기존 설명, 보유 개체 선택, 배운 행동, 동행 친구 선택과 요리 주기를 새 구성에 연결한다. 설명이 긴 상세는 왼쪽 페이지 안에서 스크롤한다. 미수집 항목은 이름과 얼굴을 가리고 현재 데이터가 제공하는 힌트를 표시한다. 수집 진행도는 오른쪽 페이지 제목 옆에 둔다.

차량 연결이 없거나 여행이 끝난 상태의 동행 선택 제한, 작업 중 행동 제한, 낚시 저장 오류·재시도는 기존 로직을 유지한다. 새 보상·능력치·획득 조건은 만들지 않는다.

## 가방

오른쪽에는 재료·요리별 아이콘 슬롯과 보유 수량을 둔다. 왼쪽에는 선택한 아이템의 큰 아이콘, 이름, 실제 수량과 현재 제공되는 용도를 표시한다. 현재 상태 데이터에는 아이템 이미지·설명 필드가 없으므로 기존 ID에 맞춘 로컬 아이콘과 사실에 근거한 짧은 문구를 사용한다.

재료는 보유량과 주방 이동을 보여 준다. 요리는 받을 친구를 고르고 1개를 주는 동작을 연결한다. 소비 전 확인 절차와 사용 가능 여부 검사는 유지한다. 보유 친구 없음, 요리 없음, 수량 0도 책 안에서 설명한다.

## 구현 기준과 격리

확인한 최신 통합 참조는 로컬 origin/dev 99309e9이다. 구현 시작 시 최신 상태를 다시 확인한다. 기본 allo checkout은 구버전이며, companion-learning-latest 작업본에는 다른 작업의 미커밋 변경이 많다. 해당 파일을 덮어쓰지 않는 별도 worktree에서 구현한다.

주요 대상은 Unity Assets/Scripts/App/AppUiViews.cs의 BuildDex·BuildInventory와 새 책 전용 partial UI 파일이다. 모든 화면이 사용하는 Sheet의 외형을 전역 변경하지 않는다. 기존 AppState와 Flutter 액션 계약을 재사용한다.

## 검증 기준

- 1600×720과 1024×576 가로 화면에서 좌우 페이지, 안전 영역, 글자·버튼 잘림을 확인한다.
- 실제 12종 얼굴을 확인하고 선택 슬롯과 왼쪽 상세가 일치하는지 확인한다.
- 미수집·빈 목록·다중 보유·긴 설명·연결 종료·수량 0을 확인한다.
- 도감 친구 선택 및 소비 확인 관련 기존 Unity 테스트를 실행한다.
- 스크롤 및 선택이 상태 갱신 후에도 유지되는지 확인한다.
- 도감과 가방의 실제 Unity 화면 캡처를 함께 제공한다. 웹 모형을 완성된 앱으로 제시하지 않는다.
