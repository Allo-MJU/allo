# ALLO 폰 앱 에셋 제작 요청서 (V2)

대상 화면은 가로 812×375 논리 px입니다. 마스터는 3배(2436×1125) 기준으로 받습니다. 이 문서의 에셋만 외부에서 제작하고, 나머지 UI(버튼·패널·진행 막대·말풍선·토글·그림자·연출)는 코드로 구현합니다. 시안은 `docs/mockups/v2/allo-flow.html`에서 열어 볼 수 있습니다.

## 1. 제작 범위

| 구분 | 제작 | 비고 |
|---|---|---|
| 로고 | 외부 | 가장 먼저 필요 |
| 배경(홈 풀밭 광장) | 외부 | 시안은 임시 이미지 1장 |
| 알 키우는 플랫폼 | 외부 | 알 키우기·부화·동행 화면 전용 |
| 아이콘 13종 | 외부 | |
| 캐릭터 12종과 알 12종 | 외부 | 시안은 PR #86의 임시 이미지 |
| 버튼·패널·막대·토글·말풍선 | 코드 | 에셋 아님 |
| 접지 그림자, 별, 하트, 껍질 파편 | 코드 | 이미지에 굽지 않음 |
| 시간대(아침·저녁·밤) | 코드 | 낮 배경 위에 색을 곱해서 표현 |

## 2. 공통 규격

- 투명 배경 PNG(알파 포함). 단색 배경으로 받은 경우 키잉이 필요하니 처음부터 알파로 받습니다.
- 그림자를 이미지에 굽지 않습니다. 바닥에 닿는 그림자는 앱에서 얹습니다.
- 워터마크, 글자, 프레임, 배경 잔여물이 없어야 합니다.
- 스타일은 3D 장난감 질감(둥근 모서리, 폭신한 광택, 낮은 채도의 따뜻한 색)으로 통일합니다.
- 외곽선이 필요한 아이콘은 코코아색 `#5C4B51`, 두께는 한 세트 안에서 같게 합니다.
- 파일명은 소문자 영문과 밑줄만 씁니다.

## 3. 에셋 상세

### 3-1. 로고 (최우선)

| 파일 | 규격 | 설명 |
|---|---|---|
| `logo_allo_wordmark.svg` | 벡터, 투명 | "ALLO" 글자. 마지막 O 자리에 알과 새싹. 시안의 흰 글자 버전 |
| `logo_allo_wordmark_dark.svg` | 벡터, 투명 | 밝은 배경용 어두운 글자 버전 |
| `logo_allo_lockup.png` | 1260×560 | 로고와 "차에서 만나는 친구들" 문구를 묶은 스플래시용 |
| `app_icon_1024.png` | 1024×1024, 모서리 직각 | 앱 아이콘. 알과 새싹만 쓴 단순형. 모서리 둥글림은 OS가 처리 |

### 3-2. 배경

| 파일 | 규격 | 설명 |
|---|---|---|
| `bg_home_day.png` | 2436×1125 | 위에서부터 도로(흰 점선, 연석), 둥근 덤불 한 줄, 평평한 풀밭. 풀밭 영역은 비워 둡니다. 캐릭터가 걷는 자리라서 큰 소품을 두지 않습니다 |

화면 위·아래 모서리에 버튼이 올라가므로, 가장자리 40px 안쪽에는 눈에 띄는 디테일을 두지 않습니다. 시안 이미지는 1679×937 임시본입니다.

### 3-3. 알 키우는 플랫폼

| 파일 | 규격 | 설명 |
|---|---|---|
| `platform_egg.png` | 가로 1050px 이상, 투명 | 등각(45°) 정사각 판. 윗면은 돌판, 가장자리는 잔디, 옆면은 나무 말뚝. 풀밭에 박힌 느낌은 앱에서 처리하니 아랫면은 평평하게 끝냅니다 |

### 3-4. 아이콘 13종

각 192×192 투명 PNG, 시안 아이콘과 같은 둥근 두꺼운 선 스타일로 만듭니다.

`icon_back`, `icon_close`, `icon_settings`, `icon_dex`(도감, 2×2 격자), `icon_trip`(기록, 접힌 지도), `icon_camp`(거점, 집), `icon_camera`(AR), `icon_flag`(도착 깃발), `icon_wish`(부탁, 하트)

상태 아이콘 4종(V2 상태 화면용)입니다. 시안에서는 코드 글자(i, …, !)로 대체했고 제작본이 오면 바꿉니다.

`icon_info`(정보, i), `icon_wait`(확인 중, 점 세 개), `icon_error`(실패·끊김, 느낌표), `icon_fish`(낚시 기록장, 팀 채택 전이라 마지막에 제작)

`icon_wish`는 시안에서 임시 선 아이콘이라 새로 필요합니다. 기본 8개(wish 제외)는 시안용 이미지가 있습니다. 상태 아이콘 3종은 하단 상태 띠(정보·대기·오류)에서 22px로 쓰이니 작게 줄여도 알아볼 수 있어야 합니다.

### 3-5. 캐릭터와 알

12종 목록은 `data/species.json`을 따릅니다. 시안 기준 이름은 길싹이, 웅덩이삐약, 등불나방, 폭풍등, 고속혜성, 바다안개 등입니다. 종 이름 불일치(#53)는 팀 결정 후 확정합니다.

종마다 아래 파일이 필요합니다.

| 파일 | 규격 | 설명 |
|---|---|---|
| `<종>/idle.png` | 512×512 | 서 있는 기본 포즈, 3/4 정면 |
| `<종>/move.png` | 512×512 | 걷는 포즈 |
| `<종>/happy.png` | 512×512 | 기쁜 표정 |
| `<종>/sleep.png` | 512×512 | 자는 포즈(밤 화면) |
| `<종>/egg.png` | 512×512 | 그 종의 알 |
| `<종>/joy.png` 시퀀스 | 512×512, 8~12프레임 | 변신 확대 화면의 기쁨 동작. 시안은 GIF지만 앱에서는 프레임 시퀀스나 WebP로 받습니다 |

모든 포즈에서 몸통의 바닥 접점이 이미지 아래쪽 가운데에 오도록 맞춥니다. 같은 종의 포즈끼리 크기와 비율이 달라지지 않아야 합니다.

## 4. 우선순위

1. 로고 4종
2. 배경 1장과 플랫폼 1장
3. 아이콘 13종(상태 아이콘 3종 포함, `icon_fish`는 후순위)
4. 캐릭터 3종(길싹이, 웅덩이삐약, 바다안개)의 전 포즈와 알
5. 나머지 캐릭터 9종
