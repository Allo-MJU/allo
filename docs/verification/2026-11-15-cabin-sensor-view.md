# 차 안 조향 연동과 자이로 시선 검증

2026-11-15 · `fix/live-service-integration-20261115`

## 확정 범위

사용자는 도시·산·해안·고속도로의 기존 근사 분류를 유지하고 이번에는 조향과 자이로부터 구현하기로 선택했다. RegionTagger의 기준점·반경과 고속도로 지속속도 추정은 변경하지 않았다. APK 작업은 보류했다.

## 변경

- 차량은 조향 센서의 표시 요약 `cornering {version,bend,receivedAtMs}`만 전달한다. 원본 각도·좌표는 추가 전송하지 않는다. 주차·역주행·최신 속도 없음·2km/h 이하·센서 실패·비정상 값·오래된 값은 사용할 수 없는 상태로 처리한다.
- 초기/주기 getter와 listener를 사용한다. 늦게 완료된 정상 getter는 받아들이되 새 완료·listener·실패·중지 상태를 옛 응답이 덮지 못하게 한다. 값과 현재 시각은 같은 lock에서 확인한다.
- 폰의 기존 전체 Unity 앱과 탐험 화면이 모두 선택적 신호를 전달한다. 신호가 없는 구버전 메시지 형식은 유지한다.
- Unity는 실내를 고정한 채 외부 월드의 짧고 제한된 방향 반응과 앞길의 곡선을 표시한다. 실제 물리 곡률이나 도로 지도를 재현하는 기능은 아니다. 이미 진입한 내비 회전과 중복 적용하지 않는다. 신호 만료·정차·움직임 줄이기에서는 효과가 가라앉고 기존 내비로 복귀한다.
- 같은 조향 수신 시각은 유효시간을 연장하지 않는다. 같은 내비 거리의 화면 재전송도 기준점을 다시 잡지 않아 이미 지난 회전을 되살리지 않는다.
- 자이로 시선은 첫 유효 자세와 현재 자세의 상대 회전으로 계산한다. 좌우 시선, 위아래 ±35도, 수평선 유지, 정면 재보정, 방향 전환·앱 복귀 보정을 포함한다. 센서가 없거나 설정을 끄면 터치 시선으로 돌아간다.
- 알·캐릭터 조작 중에는 시선 계산을 멈추고 기존 기준을 보존한다. 실제 알 터치 후 기준이 초기화되던 문제와 시선 연출이 좌석 이동을 되돌리던 문제를 회귀 테스트로 확인하고 수정했다.

## 검증 한계

센서 자세·타이밍·통신 경계를 합성 입력과 실제 Editor 카메라/알 입력 경로로 검사했다. 실제 폰의 센서 축·체감 감도, 실차 조향 좌우 부호·SDK 전달 주기는 아직 검증하지 않았다. 기본 부호는 기존 Virtual Console +120 → SDK -120 관측을 근거로 하며 실차 보정이 필요할 수 있다. `receivedAtMs`는 SDK 수신 시각이고 새 하드웨어 샘플을 보장하지 않는다.

이번 기능의 APK 빌드·Android 내보내기·설치·원격 배포는 수행하지 않았다. 프로젝트에서 실행한 Unity 테스트로 공유 재질 값이 바뀌었을 가능성이 있어 이후 해당 테스트는 공유 재질 참조를 분리했다. 동시 작업 중인 재질 변경은 임의 복원하지 않았다.
