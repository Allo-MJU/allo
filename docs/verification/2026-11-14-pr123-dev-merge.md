# PR #123 기준 dev 통합 검증

사용자 요청에 따라 #123 (`44029b1`)의 구현을 우선하여 dev (`fea7b97`, #125 포함)를 통합했다. 원본 로컬 작업은 수정하지 않고 별도 worktree에서 수행했다.

## 충돌 해결

- Flutter 컨트롤러: #123의 직접 대화·알 돌봄과 창밖 이야기 실험 비활성화를 유지했다. dev의 `StoryVoiceConfig` 요청 처리는 보존하고 사용하지 않는 `StoryDirector` import는 제외했다.
- 테스트: #123의 이야기 실험 비활성화 회귀 검사를 유지하고 dev의 음성 설정 요청 검사를 함께 보존했다.
- dev의 Pleos 광장·음성 리소스·TTS 코드는 자동 병합 결과를 유지했다. 독립 정적 검토에서 Unity 음성/Bridge와 #123 사이 추가 컴파일 충돌이나 UI 재활성화는 발견하지 못했다.
