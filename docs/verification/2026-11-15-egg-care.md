# 알 드래그·쓰다듬기·기존 디자인 적용

## 동작

- 기존 `Resources/Props/P_egg`의 메시·녹색 무늬 텍스처를 재사용한다. 표시 높이 0.24m를 유지하고, 재질은 인스턴스별로 복제해 원본을 변경하지 않는다. 읽기 불가 FBX의 정점 배열에 접근하지 않는다.
- 기본 자리(0)는 앞좌석에 가리지 않는 앞자리 사이 `Walk_Console`로 표시한다. 양쪽 창턱과 앞 바닥을 포함한 네 자리와 기존 Dart의 자리 판정은 유지한다.
- 알을 끌면 손을 따라 미리보기가 움직인다. 미리보기는 앞좌석보다 앞쪽에서 같은 화면 크기를 유지해 가려지지 않으며, 놓을 때 기존 `placeEgg` 요청으로 자리를 확정한다. 잘못된 자리·UI 위 드롭·취소는 원위치로 돌아간다.
- 현재 터치 좌표로 UI 충돌을 검사하고, 알 크기에 맞춘 짧은 왕복 문지르기를 `petEgg` 한 번으로 판정한다. 먼 곳까지 끌었다 돌아오는 동작과 마커에서 시작한 동작은 쓰다듬기로 처리하지 않는다.
- 드래그 중과 해제 프레임에는 카메라·레거시 입력을 막는다. 화면을 나가도 이전 카메라 관성이 다시 적용되지 않도록 비활성화 시 입력 상태를 정리한다.
- 친밀도는 배경 박스 없이 점수가 들어간 게이지만 표시한다. 말하기·글 입력·자리·사진 기능은 유지하고 피드백은 배경 없는 글자로 표시한다.

## Android 실행

API36 에뮬레이터에 기존 데이터를 지우지 않고 설치했다. 앱/Unity 준비 상태를 확인한 뒤 실제 터치 이벤트로 다음을 실행했다.

1. 테스트 연결 후 기존 디자인의 알과 배경 없는 게이지 확인.
2. 알을 왕복으로 문질러 친밀도 **0 → 3** 확인.
3. 앞자리 사이(0)의 알을 왼쪽 창턱(1)으로 드래그. 중간 프레임에서 알이 좌석 앞에 보이고, 드롭 후 Dart 상태 `zone=1`, `phase=incubating`, `active=true` 확인.
