# 바다 예시 일러스트 개선 검증

2026-11-15 · 구현 커밋 `18813e1`

## 변경

사용자가 지적한 바다 실험의 사각형 선체·삼각형 돛·단색 물 그림을 새 비트맵 일러스트로 교체했다.

- 목재 선체, 밧줄, 편지, 천의 주름을 표현한 배의 두 상태를 하나의 투명 아틀라스로 구성했다. 왼쪽은 펼친 돛, 오른쪽은 묶어 접은 돛이다.
- 물결과 먼 해안이 있는 3:1 바다 배경을 배와 별도 레이어로 표시한다. 배가 움직이며 배경은 고정된다.
- 기존 같은 시작점, 펼친 돛의 긴 이동과 접은 돛의 짧은 이동, 비교·모션 감소·중단 동작을 유지했다. 교육 진행과 저장 코드는 변경하지 않았다.
- Unity 가져오기에서 원본 비율과 알파를 보존하고, 바다 자막은 밝은 그림 위가 아닌 기존 어두운 무대 위에 배치했다.

원본과 내장 `image_gen` 생성 모드·정확한 프롬프트·출처·해시는 [에셋 제작 기록](../../art/sea-learning/2026-11-15/README.md)에 있다. PNG 메타데이터에도 같은 프롬프트를 넣었고 `SCAN: 2 rasters, 0 missing`을 확인했다.

## 검증

- 새 테스트로 이전 도형 렌더러를 실행했을 때 관련 4개 테스트가 실패했다.
- 새 렌더러의 Unity EditMode 전체 **299/299 통과**. 리소스 포함, 아틀라스 UV, 원본 비율, 같은 배 크기·시작점, 서로 다른 이동 끝점, 비교 범위와 모션 감소를 확인했다.
- 최신 Unity 내보내기와 Android debug APK 빌드 성공. `adb install -r`로 기존 앱 데이터를 유지해 업데이트했다.
- Android API36 에뮬레이터에서 예상 → 접은 돛 먼저 실험 → 반대 조건 → 두 결과 비교를 직접 진행했다. 검은 사각 배경, 아틀라스 옆 셀 유입, 배 잘림이 보이지 않았다.
- 2400×1080과 800×360에서 확인했고, 테스트 후 해상도는 원래 물리 기본값1080×2400으로 복원했다.
- 별도 검토자가 실제 캡처 네 장과 두 원본·소스 변경을 확인해 이번 삽화 개선 범위에 `ship` 판정을 내렸다. 기존 UI 토큰·디자인 시스템 문서는 바꿀 필요가 없다는 문서 검토도 완료했다.
