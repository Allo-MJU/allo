## 실제 화면 검증

`BookUiCapture.Run`은 빈 Unity 장면에서 **PlayMode로 진입한 뒤 실제 UGUI를 카메라로 렌더링**한다. 웹 모형이나 이미지 위에 UI를 합성한 결과가 아니다. 캡처 데이터는 검증용 fixture이며 실제 사용자 저장 상태를 의미하지 않는다.

```sh
/Applications/Unity/Hub/Editor/6000.0.85f2/Unity.app/Contents/MacOS/Unity \
  -batchmode -projectPath "$PWD/unity/allo_explore" \
  -executeMethod BookUiCapture.Run -logFile /tmp/allo-book-play-capture.log
```

`-quit`은 붙이지 않는다. 도구가 PlayMode 진입 및 검증을 완료한 뒤 종료한다. Unity의 ScrollRect는 편집 모드에서 자동 숨김 표시를 강제로 켜므로, PlayMode에서 실제 lifecycle을 실행하여 확인했다. 각 페이지의 overflow와 표시 막대의 노출 여부 및 thumb 크기도 도구에서 검증한다.

캡처 경로: `docs/work-results/unity-phone/book-ui/`.

- 도감·재료·요리 각각 1600×720, 1024×576.
- 미수집, 빈 도감, 빈 가방, 수량 0·잠긴 요리, 여행 종료, 긴 설명, 큰 수량, 스크롤 하단.
- 12종 초상 목록. 저장소에 실제 그림이 있는 6종은 얼굴 crop을 육안 확인했으며, 나머지 6종은 준비 중 표시를 확인했다.

독립 화면 리뷰에서 책등 위 장식 문구와 상세 스크롤 발견성을 지적했고 수정했다. 최종 판정은 **검토한 Unity 데모 범위에서 ship**이며, 두 지적 사항은 해결된 것으로 확인됐다.

## 제한과 에셋

- 화면 레이아웃 판정은 Unity PlayMode 캡처 기준이다. 이후 통합 APK의 Android 에뮬레이터 설치·시작도 확인했다. 실물 기기와 모든 터치 조합의 반복 검증은 남아 있다.
- 기존 소스에 없는 그림: bridge_hopper, mountain_sprite, river_glider, tide_keeper, tunnel_moth, star_owl. 다른 캐릭터 그림으로 대체하지 않았다.
- 책 배경: `unity/allo_explore/Assets/Resources/Book/OpenBook.png`. 내장 image_gen으로 생성한 원본이며 픽셀 수정 없이 사용했다. 생성 프롬프트와 출처는 `art/book-ui/provenance.md`, PNG 메타데이터에 기록했다.
- 가방 아이콘은 로컬 Unity 코드로 생성하며 최초 생성 결과를 캐시한다. 색상과 도형 데이터는 픽셀 루프 밖에서 준비한다.
