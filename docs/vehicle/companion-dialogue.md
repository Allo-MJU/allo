# Pleos 질문 버튼 화면 (#19)

첫 단계는 주차 홈의 ‘이야기’ 탭이다. 현재 차량 동행 캐릭터, 마지막 질문과 답변 하나, 질문 버튼 네 개(이름·출신·취향·기분)를 표시한다. 캐릭터는 화면 중앙에 크게 표시하고 질문을 선택하면 위 말풍선에 답변을 표시한다. 답변 말풍선을 누르면 현재 화면의 대화 상대에 맞는 Qwen 캐릭터 음성으로 읽고 다시 누르면 중지한다. 음성 준비 전 요청은 저장하지 않으며 화면 이탈·백그라운드·동행 변경 시 읽기를 중지한다. 초기화/재생 오류는 말풍선에 안내하고 텍스트는 유지한다. 자유 입력·STT·런타임 생성은 이 단계에서 추가하지 않는다. ETA·환경 질문은 필요한 실제 신호/슬롯 연결 후 확장한다.

기존 DialogueBank의 종→속성→공통 조회를 재사용한다. v2에서는 현재 알의 speciesId가 아니라 companion.speciesId를 사용한다. 질문은 클릭할 때만 조회하고 연결·대상을 다시 검사한다. 개체 또는 revision 변경, 탭 종료 시 답변을 버린다. 주행·끊김·이동·종료는 기존 PleosFlow 화면이 우선한다.

Release는 기존 검수 필터를 유지한다. ask_* 검수가 완료되지 않은 항목은 ‘이 질문의 답변은 아직 준비 중이에요.’로 표시한다. debug와 preview는 검수 전 대사가 포함될 수 있다는 표식을 표시한다. reviewedBy/reviewedAt은 임의로 변경하지 않는다. 대사 뱅크 검수 완료나 실제 AI 생성 완료를 뜻하지 않는다.

Firebase에서는 기존 인증된 세션의 game snapshot으로 현재 차량 동행을 읽는다. 질문·답변은 화면의 일시 상태이며 RTDB와 로그에 기록하지 않고 게임 상태·점수도 변경하지 않는다. 로컬 Firebase에서 폰↔차 인증·동행 동기화를 확인했다. 실행 방법은 local-firebase.md를 참고한다.

## 이야기 말풍선·TTS 업데이트

- 중앙 캐릭터(최대 340dp) 위에 팝아트 말풍선 배치: 굵은 테두리, 비대칭 꼬리, 컬러 오프셋 그림자, 하프톤 점과 이름 배지. 시스템 테마별 대비를 유지한다.
- 질문 선택은 텍스트만 갱신하며 말풍선 탭으로 음성을 시작한다. 반복 탭은 중지한다.
- Pleos TextToSpeech 3.3.1 ON_DEVICE 사용. 초기화 성공 뒤 리스너를 등록하고 해제 이후 늦은 콜백을 무시한다. Android 기본 TTS로 우회하지 않는다.
- 차량 테스트 291개(음성 준비/중지/오류/해제 테스트 5개 포함), app/preview debug 빌드 검증.
- Pleos 미리보기에서 질문 응답과 TTS 시작·완료 콜백, 라이트·다크 화면 확인. 음성 파형/청감 및 실차 검증은 수행하지 않았다.

## 원본 표시 12종 말투 정합성 (2026-11-13)

- 원본 표시 12종 모두 차량 전용 `companion-dialogue.json`에 4질문×2답변을 둔다(48키·96문장). 종별 말투는 `dialogue-style.md` 2·5절, 공통 제한은 1절을 따른다.
- 공통 6종도 직접 답변을 제공해 예전 속성/공통 답변의 되묻기·현재 날씨/시간 단정으로 빠지지 않게 한다. 신규 6종의 미정 출신은 그대로 미정으로 답한다. 공통 종의 출신은 기존 종 데이터의 만남 조건만 설명하며 실제 여행 이력을 지어내지 않는다.
- 문장 길이50자·최대3문장, 광장25자, 말버릇은 문장 끝에 한 번만 사용한다. 문서의 광장 문구와 실제 코드 문구는 회귀 검사로 비교한다.
- 공용 `data/dialogue.json`, 게임 목록/획득 조건, 로고·이미지는 직접 수정하지 않는다. `reviewedBy: null`과 release 검수 필터를 유지한다.

## 2026-11-15 선택 대화 상대의 Qwen 음성

사용자 승인으로 차량 이야기 답변을 Pleos 기본 음성에서 기존 Qwen 캐릭터 프로필로 전환했다. 기본 대화 상대는 폰에서 설정한 차량 동행이고, ‘대화할 친구 바꾸기’에서 고른 친구가 있으면 그 화면 선택을 따른다. 화면의 `subject.speciesId`와 개체/revision 키로 음성 리소스를 생성하며, 선택 변경·연결 해제·화면 이탈·백그라운드에서 이전 요청과 재생을 취소한다. 여행 목적지 안내는 이 로컬 선택을 사용하지 않는다.

질문 버튼은 텍스트만 갱신하고 말풍선 탭으로 읽는 기존 동작을 유지한다. `/v1/car/dialogue/clip`은 차량12종과 기존 대사 뱅크에서 나올 수 있는 문구만 허용한다. 앱의 release 검수 필터는 유지하며, 미설정·네트워크·합성·재생 실패 때 같은 문장을 Pleos ON_DEVICE TTS로 한 번 대체한다. Pleos까지 실패하면 텍스트와 실패 안내를 유지한다. 재생 캐시는 서버·목소리 revision·용도·종·문구별로 분리한다.

### Qwen 실패 시 Pleos 대체 (2026-11-15)

- Qwen 설정 누락, 요청/합성 오류, WAV 재생 오류 또는 다운로드·플레이어 준비가 6초 안에 끝나지 않으면 Qwen 작업을 해제하고 동일 문장을 Pleos TTS로 한 번 재생한다. 성공한 Qwen 재생은 그대로 유지한다.
- Pleos 초기화와 재생에는 합계12초 제한을 둔다. 두 경로가 모두 실패하면 오류를 알리고 텍스트를 유지한다. 여행의 기존20초 전체 안내 제한도 유지한다.
- 중지·화면 이탈·화자 교체·연결 해제는 대체 재생도 해제한다. 이전 Qwen/Pleos 완료 콜백은 새로운 안내나 STT를 시작할 수 없다.
- Pleos 대체 음성은 기본 목소리이며 원본 캐릭터 음색 복제를 의미하지 않는다. Qwen도 등록 복제본이 없어 현재 공용 프리셋을 사용한다. 원본 음색 일치는 미완료다.
