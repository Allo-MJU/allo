# ALLO 친구 도감

기준: docs/roadmap.md의 도감(Day 9) 및 완료 기준. 그리드·미수집 칸, 영문명·속성·등급, 획득 날짜·지역·날씨, 기기 저장과 재실행 복원을 구현한다.

## 화면과 흐름

포켓몬 도감의 번호·수집 현황·속성 탐색과 팰월드 도감의 큰 캐릭터 중심 상세 구성을 참고한다. ALLO 자체 캐릭터와 초록/크림 색상을 사용한다. 외부 게임 이미지나 로고를 사용하지 않는다. 참고: https://www.pokemon.com/pokedex/

차량 연결 화면 → 도감 → 획득한 친구 → 획득 기록별 차량 동행 선택 → 기존 GameController가 인증된 Firebase 세션에 동행 snapshot 발행 → Pleos 표시.

미수집 친구는 이름 대신 잠긴 모습과 획득 힌트를 제공한다. 같은 종의 여러 획득은 한 카드에 묶고 상세에서 각 획득 날짜·등급·환경·지역을 구분한다. 지역이 없는 기록을 방문 장소로 추정하지 않는다. 날씨가 기록되지 않은 경우 맑음으로 추정하지 않는다.

동행 선택은 현재 폰의 보유 기록만 허용하며 저장 실패 시 성공 표시를 하지 않는다. 관찰 기록은 상세에 열린 획득 개체의 기록을 표시한다. 로컬 선택 성공과 차량이 실제 화면에 표시한 결과는 구분해 검증한다.

## 로컬 Firebase 확인

main_local_firebase.dart의 샘플 선택 바로가기를 제거한다. 일반 도감과 동일한 저장/선택 로직을 사용하고 local.firebase. 이름공간으로 실제 사용자 도감·동행·페어링과 분리한다. 최초 샘플 획득 기록은 명시적으로 표시하며 실제 여행을 했다고 주장하지 않는다. 앱 재실행 후 샘플/추가 획득과 연결 정보를 보존한다. 실제 프로젝트의 과금·배포 설정은 변경하지 않는다.

## 확인할 항목

- 미수집 힌트·중복 획득·기록 없음·개체별 등급/선택 표시
- 좁은 가로 화면/큰 글씨에서 모든 기록과 버튼 접근
- 선택 저장 실패 및 재시도
- 저장소 격리·재생성 복원·초기 샘플 중복 방지
- 도감에서 선택한 친구가 실제 로컬 Firebase를 통해 Pleos에 표시
