# 도감·거점·이야기 통합 검증

2026-11-12, `codex/pleos-dialogue-screen`의 통합 빌드 기준.

## 연결과 동작

- 차량 주차 탭: 홈 / 도감 / 이야기 / 거점 / 여행 / 폰 공유.
- 모바일 도감과 거점은 폰에 영속 저장한다. 차량에는 collectionSummary/baseSummary와 선택 동행 표시 계약만 보낸다.
- 모바일 ‘우리 거점’에서 보유 친구를 역할별 배치하고 시설을 건설할 수 있다. 재료 차감·작업·완료 상태는 저장 성공 후 발행한다.
- 이번 모바일 조작 화면 범위는 친구 배치와 시설 건설이다. 요리/훈련 실행 UI는 아직 추가하지 않았다. 해당 core 규칙과 차량 요약 reader는 통합했다.
- 로컬 Firebase 진입점은 `local-firebase` 거점 프로필과 기존 격리 도감 저장소를 함께 사용한다. 실제 프로젝트와 섞지 않는다.

## 에뮬레이터 실측

실제 여행이 아닌 Pleos Virtual Console 주행 신호와 로컬 Firebase Auth/Functions/RTDB를 사용했다. 서버 데이터나 재료 저장값을 직접 작성하지 않았다. 도감의 세 친구는 명시된 로컬 샘플 기록이다.

1. 통합 debug APK를 Pleos와 모바일에 설치하고 앱의 연결 코드 절차로 페어링했다.
2. 재료 0개에서 Virtual Console의 누적 주행 102km를 입력했다. 모바일 저장 후 차량에 목재·돌·식재료 각 102개가 표시됐다.
3. 모바일에서 길싹이를 건설 담당으로 배치했다. Pleos에 ‘건축가 · 길싹이’가 표시됐다.
4. 모바일 ‘작업장 건설’을 눌러 목재 2·돌 1이 차감됐다. Pleos에 100/101/102와 ‘진행 중 활동 · 건설’이 표시됐다.
5. 실제 작업 시간이 지난 뒤 모바일 작업장 Lv.1, 차량 건설소 1단계가 표시되고 진행 중 활동이 사라졌다.
6. 같은 차량 APK에서 도감 3종과 웅덩이삐약 이야기 질문·응답을 확인했다.
7. 모바일 강제 종료·재실행 후 배치/재료/시설 단계가 유지되고 차량으로 다시 전송됐다.

화면 증거는 로컬 `artifacts/integrated-camp/`에 저장했다: `pleos-building.png`, `pleos-camp-complete.png`, `pleos-dex.png`, `pleos-story.png`, `phone-materials.png`, `phone-workshop.png`.
