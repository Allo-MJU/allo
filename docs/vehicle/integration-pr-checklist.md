# 도감·거점·이야기 및 차량 UI 통합

## 구현 범위
- 폰 로컬 도감과 개체별 선택 → 차량 동행 표시.
- 폰 로컬 거점 재료·역할·시설·작업 저장, 차량에는 요약 계약만 게시.
- 주차 이야기 질문 4개와 검수 정책을 지키는 대사 뱅크.
- 전체 차량 화면의 큰 메뉴·카드·분할 배치·시스템 주야간 테마.
- 주행 자동 낚시 캐릭터 확대와 정적 물가 배경. 기존 낚시 및 모션 gate 유지.
- debug 전용 로컬 Firebase 실행 경로와 저장소/인증 격리.

## 제외 범위
- 실시간 AI 자유대화·음성 입출력.
- 모바일 요리/훈련 실행 화면(규칙과 차량 요약은 포함).
- live Firebase 배포·유료 요금제 전환.
- 전체 실차/기종 인증 및 일반 화면의 주행 제한 정책 확장.
