# 광장 전용 대사

`docs/dialogue-style.md` 1·2·5절의 성격·말버릇을 따른다. 원본 표시 12종은 공통 6종과 신규 6종이며, 아래 기존 게임 12종 표는 구 ID의 표시 호환용 문구도 함께 보존한 것이다. 각 종은 광장 대사 2개를 갖는다. 사용자 요청에 따라 광장에 적용하며, 보류 중인 기존 `data/dialogue.json`과 분리한다. 기존 검수 메타데이터는 변경하지 않는다.

같은 친구를 누르면 1 → 2 → 1 순서로 교대한다. 다른 친구를 눌러도 각 친구의 순서는 유지한다(광장 화면 세션 내). 캐릭터 머리 위의 꼬리 달린 말풍선과 원본 캐릭터 WAV가 같은 문자열을 사용한다. 음성 준비 전에는 문구만 표시하며, 준비 후 말풍선을 눌러 다시 들을 수 있다.

| 친구 | 대사 1 | 대사 2 |
|---|---|---|
| 길싹이 | 풀잎이 반짝인다! 정말 신기해. | 새로운 친구를 만나고 싶어! |
| 다리뛰기 | 광장을 한 바퀴 돌고 싶어. 깡총! | 작은 길도 신나게 건너자! |
| 산정령 | 천천히 쉬어 가자. 여기선 괜찮아. | 나무처럼 든든하게 곁에 있을게. |
| 웅덩이삐약 | 첨벙첨벙, 물놀이가 제일 좋아! | 촉촉한 풀밭에서 놀고 싶어. 삐약! |
| 강미끄럼 | 바람 따라 느긋하게 흘러가자. | 조금 쉬었다 가도 좋아. 스르르. |
| 물결지기 | 마음도 파도처럼 잔잔해졌어. | 여기서 편안하게 쉬어 가자. |
| 폭풍등 | 광장에 씩씩한 등불 등장! 번쩍! | 내 작은 불빛으로 환하게 비출게. |
| 바다안개 | 살며시 다가왔어. 몽글몽글. | 조용히 쉬는 시간이 참 좋아. |
| 등불나방 | 작은 불빛만 봐도 신나. 반짝! | 환한 빛을 따라 산책하고 싶어. |
| 터널나방 | 낯선 길도 천천히 살펴보면 돼. | 어두워도 괜찮아. 함께 걸어가자. |
| 별부엉이 | 별은 저마다 다른 빛을 내. 후후. | 달빛 아래 쉬는 시간도 소중해. |
| 고속혜성 | 광장 한 바퀴, 신나게 달려! 슝! | 쌩쌩 달리고 잠깐 쉬는 거야. |

## 원본 음색 유지 (2026-11-15)

광장 12종의 24개 대사는 번들 원본 WAV로 재생한다. 클라우드 설정이 있어도 공용 Qwen 프리셋으로 덮어쓰지 않으며, 기존 클라우드 캐시도 사용하지 않는다. 이야기·여행의 신규 대사는 별도이며, 원본 음색 합성에는 캐릭터별 등록 음성이 필요하다.
