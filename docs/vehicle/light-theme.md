# 차량 라이트·다크 테마

시스템 `uiMode`에 따라 `AlloTheme`가 라이트/다크 색상을 선택한다. 시스템이 주간이면 흰 배경·짙은 초록 글자/버튼·연한 초록 카드를 사용하고 야간이면 기존 먹색·노란 강조 팔레트를 사용한다. 앱 내부에 별도 자동 시간표나 독립 토글은 두지 않는다.

공유 프레임, 연결/권한/주행/주차/상태 화면, 알과 진행바, 낚싯줄·수면/달리기 효과는 테마 역할 색상을 사용한다. 캐릭터 고유 아트와 QR 흑백은 유지한다. 분할 창의 기존 스크롤·고정 탭 배치는 유지한다.

첨부된 새 ALLO 로고는 [원본과 투명화 설명](../../art/design/logo/woodland/README.md)에 따라 화면용 리소스로 적용했다. 헤더 폭을 늘려 상세 그림을 표시한다. Android 런처 아이콘은 기존 A 전용 아이콘이다.

## 확인 범위

- 차량 단위 테스트 260개 통과(테마 3개 추가). 양쪽 테마의 본문/버튼 대비 4.5:1, 진행바 대비 3:1 이상 검사.
- 차량 debug/release 및 preview APK 빌드 통과. 실제 차량 debug 앱 설치 완료.
- Pleos 에뮬레이터 실제 분할 창에서 주차 홈·주행·연결 라이트 화면, 시스템 night yes/no 전환 확인. 확인 후 라이트로 복원.
- 캡처는 실제 Compose 화면에 테스트 데이터를 표시한 preview 앱이다. 실제 폰/Firebase 연동이나 실차 주야간 신호 검증을 뜻하지 않는다.
