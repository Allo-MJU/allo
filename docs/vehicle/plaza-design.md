# Pleos 광장: 숲속 친구 쉼터

## 레퍼런스와 적용

- [Animal Crossing: Pocket Camp Complete — Nintendo](https://www.nintendo.com/en-gb/Games/Smart-device-games/Animal-Crossing-Pocket-Camp-Complete-2711347.html): 나무·가구로 둘러싼 야외 공간에 동물들이 머무는 구성을 참고. ALLO에서는 가장자리 오두막·벤치·꽃밭과 열린 잔디 공간으로 해석했다.
- [Sonic Adventure 2 Chao Garden — SEGA](https://sonic.sega.jp/sonicadv2/0601/shots_e.html): 초록 정원과 연못, 생물들이 쉬는 공간이라는 방향을 참고. 개별 이동/휴식 주기를 사용한다.

게임 이미지·캐릭터·UI는 앱에 복사하지 않았다. `plaza_garden.png`는 imagegen으로 새로 생성한 ALLO 전용 배경이다. 기존 ALLO 캐릭터 원본은 유지한다.

## 표시와 상호작용

- 주차 홈에만 표시. 현재 수집 요약과 제공 원본 목록에 모두 있는 친구 중 최대 6종을 체크로 선택한다. 최초 설정이 없을 때만 차량 동행 우선 기본값을 사용하며, 이후에는 사용자의 선택을 따른다. 자동 페이지 교체는 사용하지 않는다. 폰/core/계약 수정 없음.
- 캐릭터마다 다른 동선·속도·휴식. 발 위치 기반 배치, 깊이에 따른 크기·그림자·그리기 순서, 이동 방향 전환.
- 탭한 친구는 그 위치에서 대기한다. [광장 전용 성격 대사](plaza-dialogue.md)가 연결된 종은 말풍선과 Pleos TTS를 사용하고, 새 원본 6종은 대사 준비 중을 표시한다. 다른 친구 선택 시 원래 위치에서 이동을 재개한다.
- 대사는 선택한 캐릭터 머리 위에 꼬리 달린 말풍선으로 표시한다. 말풍선 폭과 좌우 위치를 광장 경계 안으로 제한하며, 장면 아래 대사 패널은 사용하지 않는다. 광장은 보류된 기존 대사 뱅크와 분리하며, 기존 이야기 화면의 검수 필터·메타데이터는 변경하지 않는다.
- 작은 창은 2열의 여유 있는 동선, 넓은 창은 3열의 불규칙 동선. 다크 모드는 배경에 밤색 조명과 작은 불빛 적용.
- 앱 비활성/연결 해제/시스템 애니메이션 끄기 시 배회 중단. 화면 이탈·연결 변경 시 음성 중단.

## 앞선 광장 구현 검증

아래 수치는 원본 캐릭터 교체·체크 선택·이야기 친구 선택 추가 전의 검증 이력이다. 당시 12종과 현재 제공 원본 12종은 공통 6종 외 목록이 다르므로 새 6종의 검증으로 해석하지 않는다.


통합 작업공간에서 차량 단위 테스트 309개 통과, 앱/preview 빌드 성공. 후속 PR은 최신 dev에서 광장 변경만 분리해 312개 테스트와 앱/preview 빌드를 통과했다. 추가 6종 포함 12종을 에뮬레이터 두 페이지에서 확인했다. 전체 라이트, 841px 분할 다크, 420px 좁은 화면을 확인했다. 이름 배경은 제거하고 텍스트와 그림자만 유지한다. 7개 폭의 240초 동선 샘플로 캐릭터/이름 영역의 경계와 겹침을 검증했다. 에뮬레이터 미리보기는 테스트 수집 데이터이며 실제 폰 왕복 검증과 구분한다.

### 광장 친구 선택과 복귀

- 친구들 메뉴는 현재 수집 요약과 제공 원본 목록의 교집합을 표시한다. 최대 6종을 체크하고 해제할 수 있다. 6종 선택 상태에서는 다른 종을 추가하기 전에 하나를 해제해야 한다.
- 최초 선택이 없을 때는 차량 동행 우선 최대 6종을 기본 표시한다. 체크를 바꾼 뒤에는 차량 앱 로컬 설정에 선택 ID를 저장한다. 앱 재실행에도 유지하며 현재 소유하지 않은 ID는 표시하지 않는다. 모두 해제한 명시적 빈 선택은 빈 광장으로 유지한다.
- 이 설정은 광장의 표시 선택이다. 폰의 동행·수집·재료 보상 상태를 변경하지 않는다. 차량 앱의 로컬 설정이므로 폰이나 다른 차량으로 동기화하지 않는다.
- 친구들·거점·폰 공유에는 `광장으로` 복귀 버튼을 제공한다. 광장 이외 탭의 시스템 뒤로가기도 광장으로 돌아간다. 친구들에는 `선택 완료 · 광장으로` 버튼도 있다.
- 광장 오른쪽 위 마릿수/페이지 버튼과 왼쪽 아래 장식 문구는 제거한다. 선택 수와 6마리 제한은 친구들 화면에 안내한다.

### 이야기 친구 선택과 대사 경계

이야기 화면의 `대화할 친구 바꾸기`에서 수집한 제공 원본 친구를 한 종 부를 수 있다. `차량 동행과 이야기`를 선택하면 폰에서 정한 실제 차량 동행을 대화 대상으로 사용한다. 이야기 친구 선택은 광장 표시 체크·실제 차량 동행과 독립이며 `companion`을 쓰거나 이동 요청을 만들지 않는다.

선택 교체 시 답변과 TTS를 정리하며, 질문·말풍선 재생 시 최신 연결과 소유 상태를 다시 확인한다. 선택한 종이 수집 요약에서 사라지거나 연결이 끊기면 대화를 비활성화한다. 이 대화 대상은 광장 설정처럼 영구 저장하지 않는다.

새 원본6종은 말투 가이드5절을 바탕으로 고유 광장 인사2개와 이야기4질문 각2답변을 연결했다. 기존 대사 뱅크의 검수 정책을 유지하므로 신규 이야기 답변은 debug에서 사용하며 release에는 실제 검수 표시가 필요하다. 다른 종의 성격·이름·속성을 대신 대입하지 않는다. 게임 획득 조건은 여전히 미정이다.

주행 수집 기준은 [PR #112](https://github.com/Allo-MJU/allo/pull/112), [이슈 #68](https://github.com/Allo-MJU/allo/issues/68), [이슈 #62](https://github.com/Allo-MJU/allo/issues/62)를 따른다. 폰의 차량 동행 1마리가 낚시 연출을 하며 재료 지급은 관측 거리 1km당 목재·돌·식재료 각 1개와 60초 간격 창밖 보기 규칙이다. 광장·이야기 표시 선택은 이 계약을 변경하지 않는다.

### 이번 후속의 검증 범위

선택 상한·해제·빈 선택·소유 필터링과 이야기 guest의 소유/연결 재검증을 위한 회귀 테스트를 추가했다. 원본 해시와 걷기 프레임 검사는 별도 테스트로 관리한다. 위의 312개 통과 및 분할·다크 스크린샷은 이번 후속 이전 이력이며, 이번 최종 빌드·테스트·실화면 확인 결과는 통합 완료 시 별도로 기록한다.


최종 확인: 차량 단위 테스트 321개 통과(실패/오류/스킵0), app/preview debug 빌드 및 Pleos 설치 성공. 전체 라이트 창에서 친구 체크 추가·광장 복귀·원래 체크 복원, 거점 복귀, 이야기 친구 선택 팝업과 구름발 표시/미등록 답변 안내를 확인했다. 기존/신규 산책 프레임을 화면에서 확인하고 12종 파일·8프레임 경계·방향을 자동 검사했다. 이번 변경 후 12종 각각의 실시간 이동 전체 주기, 분할·다크 재검증 및 실폰 수집 연결은 수행하지 않았다.

Figma 상단 버튼은 아래 v2 Toy 후속 구현으로 반영했다.


### Figma 기반 공통 버튼

[Components → v2 Toy Button (48:109)](https://www.figma.com/design/TRrSfvlCajZCNcf8t9hK1u/ALLO-Design-System?node-id=48-109)의 디자인 컨텍스트·스크린샷을 확인해 Compose 공통 ToyButton으로 구현했다. 사용자 피드백에 따라 흰색/강한6dp 턱을 그대로 복제하는 대신 숲·종이 화면에 맞는 크림색(#F4EFDF)·이끼색(#42664C)과 낮은2→1dp 눌림으로 조정했다. 차량 터치 높이72dp, 반경24dp, 굵은20sp/행간26sp는 공유하며 다크에서는 어두운 이끼색(#35483A)을 사용한다. 한글은 Android 시스템 글꼴을 사용하고 외부 이미지 에셋은 없다.

상단 탭, 광장 하단3메뉴, 광장 복귀/공유, 이야기 친구 호출·질문·팝업 닫기, 친구 선택 완료, 여행 후보/내비 요청 수락 및 ScreenAction 기반 연결 버튼을 같은 컴포넌트로 통일했다. 광장 하단은 최소144dp 너비·12dp 간격으로 중앙에 묶었다. 선택카드·라디오/체크박스는 별도 선택 의미를 유지한다. 실제 차량 동행·질문 검증·TTS·여행 수락 콜백과 disabled 조건은 유지한다.

최종 테스트321개 통과/실패0, app·preview 빌드 및 Pleos 설치 성공. 전체 라이트 광장/이야기 렌더 확인. 공통 버튼의600dp 다크 레이아웃과 탭 전환을 확인했으며 원래 전체 라이트로 복원했다. 여행 후보/내비 요청의 실제 폰 왕복은 재검증하지 않았다.
