# 제공 캐릭터 6종 낚시 동작

2026-11-13 사용자가 원본 외형을 유지한 낚시 동작 프레임 제작을 승인했다. 제공된 6종의 동작 파생 에셋이며 원본, 기존 공통 6종 시트, 로고, 캐릭터 ID와 획득·보상 규칙은 변경하지 않는다.

| ID | 표시 이름 | 낚싯대 방향 |
| --- | --- | --- |
| breeze_wyrm | 산들룡 | 오른쪽 |
| cloud_strider | 구름발 | 오른쪽 |
| dewcap | 이슬갓 | 오른쪽 |
| dune_roller | 모래돌이 | 왼쪽 |
| ember_crab | 불씨게 | 오른쪽 |
| pebble_orbit | 조약별 | 오른쪽 |

각 `car/app/src/main/assets/fishing/<id>/fish.png`는 원본 idle 아트를 참조한 투명 PNG이며 같은 폴더의 `generation-provenance.md`에 도구·프롬프트·원본/출력 해시를 기록한다. 산들룡은 원래 두 깃날개로 낚싯대를 잡는다.

시트는 4열×2행, 1774×887px이다. 기다림→입질→당김→포획→기쁨→놓침→내림→기다림의 8프레임을 기존 낚시 타임라인 `[0,0,0,1,2,3,4,5,6,7,7,7]`, 슬롯당 300ms(한 주기 3.6초)로 재생한다. 날개·발·촉수·집게·돌손의 자세와 낚싯대·물고기가 바뀐다.

`PetSpriteSheets`에서 Fishing 동작으로 등록하며 DrivingScreen의 기존 공유 `elapsedMs`, 주행 신호·연결·생명주기·시스템 모션 설정을 따른다. 새 시트에만 8% 고정 렌더 여백과 기존 알파 컷오프 32를 적용한다. `FishingSceneProfile`의 몸·바닥·찌 좌표는 여백 적용 후 좌표다. 조약별의 6번 프레임은 찌가 없는 빈 바늘이므로 물 접점 효과를 생략한다.

검증은 단위 테스트와 debug APK 빌드, 원본·로고·게임 데이터 해시 대조, APK 에셋 바이트 대조, Pleos Connect 2.1.0 에뮬레이터의 6종별 8개 고정 프레임과 6초 실시간 재생으로 수행한다. 에뮬레이터 주행 화면은 실제 DrivingScreen을 사용하는 명시적 테스트 데이터이며 폰/실차 연결 검증을 의미하지 않는다.

최종 결과: 단위 테스트 326개(실패·오류·스킵 0), 빌드 성공, 보호 파일 136개 해시 불변 및 두 APK의 신규 에셋 바이트 일치를 확인했다. 6종의 48개 고정 프레임과 종별 4.46~5.74초 실시간 영상에서 한 주기 이상 재생을 확인했다. 산들룡의 추가 사지와 투명 배경도 별도 검수했다.
