# 창밖 이야기 탐험 · 한국어 대사 초안 v1

작성: 2026-11-13 · 8편 + 공통 상황 대사 · 앱 미연동·콘텐츠 검수 전

기준: [창밖 이야기 탐험 기획](superpowers/specs/2026-11-13-window-story-learning-design.md), [캐릭터 기준](ai-character-dialogue.md).

## 사용 규칙

- 한 행은 말풍선 하나다. 대사는 공백 포함 50자 이내로 작성했다. 연출 조건은 제작자용이며 아이에게 표시하지 않는다.
- 캐릭터 이름은 말투 기준이다. 실제 화자는 현재 동행 친구이며, 종별 말버릇은 해당 종일 때만 사용한다. 다른 친구가 말할 때는 “삐약”, “후후”를 제거한다.
- 공통 흐름: 초대 → 도입 → 선택 → A/B 반응 → 비교 안내 → 반대 선택의 반응 → 발견 → 설명(선택) → 결말. 비교는 한 번만 실행하고 다시 비교 안내로 되돌리지 않는다.
- 선택 버튼의 첫 번째가 A, 두 번째가 B다. 발견의 첫 버튼은 설명, 두 번째는 결말로 이동한다. 설명 뒤에는 결말로 합류한다.
- 카드 행은 카드 본문·제목이다. 결말의 “카드 담기”를 누른 뒤 저장 결과에 따라 공통 대사를 표시한다. “더 궁금해”는 저장 성공 뒤 선택적으로 연다.
- “한 번 더”는 선택 단계부터 재생한다. 수집 보상은 중복되지 않는다. 자동 초대·부화 우선권·중단 규칙은 기획서를 따른다.
- 모든 행동은 화면 속 모형에 적용한다. 결과 대사는 해당 연출이 끝난 뒤에만 표시한다. 실제 사물 인식·실제 차량 제어를 전제로 하지 않는다.
- 문장은 콘텐츠 초안이다. 과학 사실·시뮬레이션 결과 일치 검수와 아이 대상 가독성 검증은 아직 수행하지 않았다.

## 1. 도로 · 씨앗의 여행 가방

- 이야기 ID: `road_seed`
- 말투 기준: 길싹이
- 연출 조건: 같은 무게의 가상 씨앗 모형을 같은 높이에서 놓는다. 날개 유무만 바꾸고 동일한 바람을 적용한다. 실제 식물 종을 특정하지 않는다.

| 단계 | 대사 | 버튼 / 카드 제목 |
| --- | --- | --- |
| 초대 | 씨앗도 여행 가방이 있을까? 우리 하나 만들어 보자! | 가방 만들기 / 나중에 |
| 도입 | 여긴 상상 작업실이야. 씨앗 모형이 여행을 준비해. | 다음 |
| 선택 | 어떤 모양으로 바람을 만나게 해 줄까? | 날개 달기 / 둥글게 만들기 |

| B 반응 | 톡! 둥근 씨앗은 먼저 바닥에 내려왔어. | 비교해 보기 |
| 비교 안내 | 같은 높이, 같은 바람! 이번엔 다른 모양을 놓아 보자. | 다른 모양 놓기 |
