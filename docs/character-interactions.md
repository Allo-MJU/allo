# 캐릭터 상호작용과 차량 반응

사용자 담당 범위인 터치, 드래그, 캐릭터 이벤트, 차량 액션에 따른 반응을 동행 화면에 연결한다. #51 창가 통합 위에 적용하며, #49 최신 와이어프레임(v4, ef65d72)의 포즈 이름과 모션 감소 원칙을 참고했다. 배경은 정적으로 유지한다. 이후 확정된 가로 게임 제공 요구와 화면 전환 설계는 [가로 게임 화면 설계](phone-landscape-design.md)를 따른다. 품기·부화·동행은 가로 장면과 조작 영역을 분리했다. 품기 알은 버튼 대신 직접 눌러 감싼다.

## 표시 규칙

| 입력 | 반응 | 유지 시간 |
| --- | --- | --- |
| 캐릭터 터치 | HAPPY, 인사와 짧은 바운스 | 900ms |
| 캐릭터 드래그 | HAPPY, 창 안에서 이동 | 놓을 때까지 |
| 드래그 놓기/취소 | 원래 위치로 복귀 | 600ms |
| 먹이 / 놀이 | HAPPY, 기존 돌봄 메시지 | 1200ms |
| 창밖 보기 | SURPRISED, 발견 메시지 | 900ms |
| 출발 / 정차 | MOVE / IDLE | 900ms 후 기본 상태 |
| 급제동 / 급조향 | SURPRISED, 의자에 매달리기와 짧은 흔들림 | 1500ms |
| 비 시작 / 바다·산 풍경 변화 | HAPPY, 창문에 붙기 | 2400ms |
| 정차 지속 | SLEEP | 이동할 때까지 |

기본 상태는 이동 중 MOVE, 정차 후 8초부터 SLEEP, 그 외 IDLE이다. 이동 판정은 3km/h 이상, 정차 판정은 P 또는 0.5km/h 이하로 구분하여 저속에서 반복 전환을 줄인다. 8초와 입력 제한 400ms는 이 구현의 조정 가능한 표시 기본값이며 서버 규약이 아니다.

우선순위는 급제동/급조향 > 드래그 > 돌봄/창밖 > 터치/놓기 > 창문 붙기 > 출발/정차다. 낮은 우선순위 사건은 대기열에 남기지 않는다. 급변은 진행 중 드래그를 취소하고 의자에 매달리는 위치로 전환한다. 동일 사용자 입력은 400ms 안에 반복하지 않으며 실제 드래그 종료는 항상 허용한다. 급변 반복 수신으로 놀람 시간을 무한 연장하지 않는다. 동시에 급제동과 급조향이 오면 급제동을 표시한다.

## 수명과 신호 처리

- 첫 차량 신호는 기준선만 설정한다. 누적 harshBrake/harshSteer의 증가분만 사건으로 처리한다.
- 중복/역순 ts는 무시하고, 누적 카운터 감소는 새 기준으로 받아들여 과거 급변을 재생하지 않는다.
- 앱 중단, 회차 변경, 동행 종료 시 표시 상태와 드래그를 초기화한다. 앱 복귀 시 중단 전 캐시 대신 첫 새 차량 신호를 기준선으로 사용한다.
- 신호가 없는 상태에서도 터치는 가능하다. 차량 방향 데이터가 없으므로 좌/우 조향 방향을 추정하지 않는다.
- 표시 모델은 게임 점수, 서버 이벤트, 돌봄 카운터를 변경하지 않는다. 기존 먹이/놀이/창밖 버튼의 실제 동작을 관찰한다.

## 입력과 접근성

캐릭터 영역에서 시작한 드래그만 이동에 사용하며, 바깥 세로 제스처는 화면 스크롤로 전달한다. 캐릭터는 창 내부로 제한되고 놓으면 200ms에 원위치로 돌아온다. 스크린리더에는 이름·현재 포즈·누르기 액션과 반응 메시지를 제공한다. 모션 감소 설정에서는 바운스·흔들림·복귀 보간을 생략하고 메시지와 상태 아이콘을 유지한다.

최종 포즈별 아트가 아직 없어 기존 종별 스프라이트에 상태 아이콘과 짧은 변환 모션을 적용했다. 정식 포즈 에셋의 연결은 별도 작업이다.

## 환경에 붙는 동작

- 비(`rain` 또는 와이퍼 작동)가 시작되거나 바다/산 풍경으로 바뀌면 **창문 붙기**를 2.4초 표시한다. 왼쪽 창으로 이동해 손의 접촉 표시를 남기며, 터치·드래그·돌봄으로 중단할 수 있다.
- 급제동·급조향은 **의자 매달리기**로 표현한다. 오른쪽 등받이에 손을 걸고 기존 놀람 메시지/짧은 흔들림을 표시한다. 좌우 조향 방향을 뜻하지 않는다.
- 자동 창문 이벤트는 8초 간격으로 제한한다. 첫 차량 샘플·복귀·역순 신호로 과거 환경 변화를 재생하지 않고, 높은 우선순위로 거부된 사건을 나중에 재생하지 않는다.
- 둘 다 만료되면 중앙으로 복귀한다. 모션 감소 시 이동/흔들림 없이 부착 위치와 메시지만 표시한다. 손·등받이는 임시 벡터 표현이며 포즈별 최종 아트는 아직 미제공이다.

로컬에서 두 동작을 함께 확인하려면 `flutter run --dart-define=FEED=fake --dart-define=SCENARIO=character_tour`를 사용한다. 8초마다 맑음→비→바다→산 환경이 바뀌고 5초마다 차량 급변이 발생한다. 같은 시점에는 급변이 우선한다.

### 차 안 전체 시점

#47 `b5c155d`의 뒷좌석 중앙 시점을 통합했다. 앞유리·양옆 창·앞좌석 두 개·대시보드·룸미러가 보이며, 별도로 그리던 올리브 좌석은 중복을 막기 위해 제거했다. `CabinLayout`의 왼쪽 창문 접촉점과 오른쪽 앞좌석 등받이 윗단을 캐릭터 손 앵커로 함께 사용한다. 입력은 캐릭터만 받고 배경은 가로채지 않는다.

지나가는 생물과 도감에 수집한 친구는 유한 재생 이벤트이며 정차·모션 감소·앱 중단에서 중지된다. 배경 그림은 이동하지 않는다. 상세 정책은 [통합 기준](phone-presentation-integration.md)을 참고한다.
