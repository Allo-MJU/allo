## 적용

- `phone/lib/theme/allo_colors.dart`는 위 토큰 중 이번 화면에서 쓰는 색·크기·모션 값의 Flutter 대응이다. 화면은 발견 배경·본문·주요 행동 역할을 사용한다. #48/#49가 병합되면 토큰 원본과 이 대응을 함께 갱신한다.
- 앱 글꼴은 Asta Sans 가변 폰트, 테마 시드는 동작 초록이다. 공식 Google Fonts 원본과 OFL 전문을 `phone/assets/fonts/asta-sans/`에 번들했다. 외부 네트워크 없이 렌더링한다.
- 부화는 금 3컷→빛 2컷→등장을 2400ms에 재생한다. 모션 감소에서는 이동 없이 결과를 200ms 페이드한다. 건너뛰기는 결과로 바로 간다. 주요 버튼은 ‘친구 만나기’다.
- 알·생물 이미지는 최신 스타일라이즈드 3D 방향에 맞춰 보간한다. 종별 실제 원본이 없는 상태에서 캐릭터 대응을 추측하지 않는다. 현재 종 데이터와 이름·등급은 게임 계약을 따른다.
- 알 성장·부화 파일명은 D의 최신 art/README.md에서도 유지되므로 해당 계약으로 읽는다. 제공되지 않은 프레임은 기본 그림으로 표시한다.

## 아직 합치면 안 되는 차이

1. #47은 3겹 패럴랙스를 사용하지만 #49의 디자인 시스템 10절과 품기 와이어프레임은 움직이는 배경을 금지한다. 통합 시 장면·날씨 선택은 보존하고 배경 이동을 제거하거나 A·D가 기준을 조정해야 한다. 이번 PR은 배경 이동을 추가하지 않는다.
2. #47과 이번 PR 모두 품기 알 부분을 바꾼다. 통합 시 `WindowView.child`에 `EggArt(size: 120)`를 넣고 기존 흔들림·돌봄·종료·반복 부화 전환을 보존한다. 어느 쪽 화면 전체를 덮어쓰지 않는다.
3. #49의 새 6종과 등급 배지 대응은 C 확인 대상이다. `species.json`을 임의로 바꾸거나 도감 12종을 6종으로 줄이지 않는다. 실제 캐릭터 이미지와 HAPPY 포즈 적용은 종·파일 대응이 정해진 뒤 진행한다.
4. 하단 탭 3개와 전체 품기 카드 재배치는 별도 화면 흐름 작업이다. 이번 변경은 성장·부화 및 이를 지원하는 글꼴·테마에 한정한다. 전체 와이어프레임 구현 완료로 해석하지 않는다.
