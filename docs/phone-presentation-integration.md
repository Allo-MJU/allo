## 가로 게임 제공 기준

사용자의 후속 요구에 따라 폰 게임 화면은 가로를 기준으로 설계한다. #49 v4의 세로 화면 배치보다 이 요구를 우선하며 색·글꼴·모션 감소·터치 크기는 재사용한다. [가로 게임 화면 설계](phone-landscape-design.md)에 변경 범위와 완료 조건을 기록했다. 품기·부화·동행의 가로 배치는 구현했으며 보조 화면의 전환은 남아 있다. 감싸기는 최신 사용자 요구에 따라 별도 버튼 대신 알 직접 터치로 제공한다.

## 적용

- `phone/lib/theme/allo_colors.dart`는 위 토큰 중 이번 화면에서 쓰는 색·크기·모션 값의 Flutter 대응이다. 화면은 발견 배경·본문·주요 행동 역할을 사용한다. #48/#49가 병합되면 토큰 원본과 이 대응을 함께 갱신한다.
- 앱 글꼴은 Asta Sans 가변 폰트, 테마 시드는 동작 초록이다. 공식 Google Fonts 원본과 OFL 전문을 `phone/assets/fonts/asta-sans/`에 번들했다. 외부 네트워크 없이 렌더링한다.
- 부화는 금 3컷→빛 2컷→등장을 2400ms에 재생한다. 모션 감소에서는 이동 없이 결과를 200ms 페이드한다. 건너뛰기는 결과로 바로 간다. 부화 버튼은 v4의 ‘동행 시작’이며 높이 56이다.
- 알·생물 이미지는 최신 스타일라이즈드 3D 방향에 맞춰 보간한다. 종별 실제 원본이 없는 상태에서 캐릭터 대응을 추측하지 않는다. 현재 종 데이터와 이름·등급은 게임 계약을 따른다.
- 알 성장·부화 파일명은 D의 최신 art/README.md에서도 유지되므로 해당 계약으로 읽는다. 제공되지 않은 프레임은 기본 그림으로 표시한다.

## 창밖 통합 및 남은 범위

1. #47의 3겹 패럴랙스와 이동하는 비를 제거하고 최신 #49 10절의 배경 이동 금지를 적용했다. 그림 층·밤 틴트·고속도로·비 세기는 보존한다. 별도 런타임 모션 스위치 없이 앱과 테스트 모두 같은 정지 화면을 쓴다. 장면·날씨 변경만 200ms 페이드한다.
2. `WindowView.child`에 `EggArt(size: 120)`를 배치했다. 기존 흔들림·돌봄·종료·반복 부화 전환을 보존하고, 창밖 설명과 알 성장 단계는 별도 접근성 노드로 제공한다. 동행 화면도 동일한 정지 창을 사용한다.
3. 지역 전환 4초 안정화는 #47의 임시 기준을 보존한다. 단조 시계로 측정하며 A의 실제 위치 갱신 주기 검증 후 조정한다. 터널 진입/이탈과 날씨 변경은 즉시 반영한다. 통신이 끊겼다고 임의로 주행 종료를 판단하지 않는다.
4. #45 원래 요구는 속도 비례 스크롤이다. 이 통합은 더 최근의 #49 디자인을 따른 변경 제안이며 #45가 합의 변경된 것으로 간주하지 않는다. 검토자가 이 차이를 확인할 수 있도록 후속 PR에 명시한다.
5. #49의 새 6종과 등급 배지 대응은 C 확인 대상이다. `species.json`을 임의로 바꾸거나 도감 12종을 6종으로 줄이지 않는다. 실제 캐릭터 이미지와 HAPPY 포즈 적용은 종·파일 대응이 정해진 뒤 진행한다.
6. 하단 탭 3개와 전체 품기 카드 재배치는 별도 화면 흐름 작업이다. 이번 변경은 성장·부화, 이를 지원하는 글꼴·테마, 창밖 장면 통합에 한정한다. 전체 35화면 구현 완료로 해석하지 않는다.
