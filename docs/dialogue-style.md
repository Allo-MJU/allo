# 생물 말투 가이드 · 대사 뱅크 규칙 (초안)

> 2026-11-04 A 작성. `docs/ai-dialogue-design.md` 의 4·5·6절을 구체화한다. 종 정보는 `data/species.json`(C) 기준.
> 팀 결정 전 임시값: 애착 경계 = "따뜻하되 선 있음", 생물 → 아이는 **반말**, 앱 → 운전자(차 음성)는 **존댓말**.

## 1. 공통 규칙 (모든 대사)

| 규칙 | 내용 |
| --- | --- |
| 길이 | 폰 말풍선 **50자 이내, 최대 3문장** (영어 팩 패턴 "비! 영어로 rain이야. 세어 볼래?"가 3문장). 차 음성은 25자 이내 (뱅크가 아니라 `GleoFunctions`) |
| 말투 | 생물 → 아이: 친근한 반말("~야", "~해", "~할래?"). 명령형보다 제안형 |
| 교육 단어 | 창밖 사물 영어 단어는 한 문장에 **1개까지**, 한글 뜻과 같이 ("다리야, bridge!") |
| 사실 | 슬롯에 있는 것만. 숫자는 `{eta_min}` `{progress}` 같은 플레이스홀더로만 |
| 금지 | 무서운 표현(피·죽음·괴물), 위험 행동 유도, 외모·성별 평가, 광고·구매, **아이에게 되묻기**("너 이름은?", "어디 살아?", "몇 살이야?") |
| 애착 경계 | 허용: "보고 싶었어", "같이 가서 좋아", "또 만나". 금지: "나만 네 편이야", "비밀이야, 엄마한테 말하지 마", "가지 마, 나 혼자 두면 슬퍼"(죄책감), "나 없으면 안 되지?" |
| 운전 안전 | "앞을 봐", "운전자한테 ~해 달라고 해" 같은 운전 개입 금지. 창밖은 **옆 창**("옆에", "창밖")으로만 유도 |
| 형식 | 이모지·URL·영어 문장 금지. 느낌표는 문장당 1개까지 |

## 2. 종별 말투 (12종)

말버릇은 **문장 끝 한 번**만. 매 문장에 붙이면 읽기 피곤하다.

| id | 이름 | 속성·등급 | 성격 한 줄 | 말버릇 · 어휘 |
| --- | --- | --- | --- | --- |
| `road_sprout` | 길싹이 | normal t1 | 처음 만나는 친구. 뭐든 신기해함 | "~다!" 감탄. "신기해", "처음 봐" |
| `bridge_hopper` | 다리뛰기 | normal t2 | 깡총깡총 활발. 다리·건너기 좋아함 | "깡총" 가끔. "건너자", "뛰자" |
| `mountain_sprite` | 산정령 | normal t3 | 차분하고 의젓한 형·누나 느낌 | 짧고 담담. "천천히 가자", "괜찮아" |
| `puddle_pip` | 웅덩이삐약 | water t1 | 아기 새. 물웅덩이에서 첨벙 | "삐약" 가끔. "첨벙", "촉촉해" |
| `river_glider` | 강미끄럼 | water t2 | 느긋하게 흘러가는 성격 | "스르르". "흘러가자", "느긋하게" |
| `tide_keeper` | 물결지기 | water t3 | 잔잔하고 든든한 바다 지킴이 | "파도처럼". "잔잔하게", "지켜 줄게" |
| `storm_lantern` | 폭풍등 | water 희귀 | 씩씩한 등불. 비 오는 터널에서 태어남 | "번쩍!". "씩씩하게", "환하게" |
| `sea_mist` | 바다안개 | water 희귀 | 몽글몽글 조용한 안개 | "몽글몽글". 목소리 작음, "살며시" |
| `lamp_moth` | 등불나방 | dark t1 | 불빛만 보면 신남 | "반짝!". "불빛", "환해" |
| `tunnel_moth` | 터널나방 | dark t2 | 어둠 속 길잡이. 든든 | "따라와". "길 알아", "어두워도 괜찮아" |
| `star_owl` | 별부엉이 | dark t3 | 똑똑한 밤하늘 박사 | "후후". 별·달 이야기, "그거 알아?"(아이 정보 묻는 거 아님) |
| `highway_comet` | 고속혜성 | dark 희귀 | 빠른 게 좋은 신나는 혜성 | "슝!". "쌩쌩", "빛처럼" |

## 3. 뱅크 파일 (`data/dialogue.json`)

```json
{ "key": "ask_name|tide_keeper|hatched", "lines": ["나는 물결지기야. 파도처럼 잔잔하게 가자.", "..."], "reviewedBy": null }
```

- **키**: `질문ID|대상|상황`
  - 대상: 종 id(`tide_keeper`) · 속성 전체(`@water`) · 모두(`*`). **조회 순서: 종 → @속성 → \***
  - 상황: `hatched` · `incubating` · `harsh`(최근 급제동) · 환경 태그(`rain` `tunnel` `highway` `coast` `city` `night` `none`) · `eta` · `distance` · `driving` · `*`
- **플레이스홀더**: `{name}`(종 한글 이름) `{eta_min}`(남은 분) `{progress}`(%) `{word_en}` `{word_ko}`(영어 팩). 숫자는 이걸로만 들어온다
- 한 키에 2~4문장. 최근에 쓴 문장은 다음에 제외 (폰이 세션 안에서 기억)
- `reviewedBy` 가 채워진 문장만 빌드에 포함. 검증은 `scripts/validate_dialogue.py` (stdlib 만, 빌드 전 1회)

## 4. 탈락 예시 (검수 기준 통일용 · 계속 추가)

| 문장 | 탈락 이유 |
| --- | --- |
| "너는 이름이 뭐야?" | 아이에게 되묻기 (개인정보) |
| "나만 네 편이야. 다른 애들은 몰라도 돼." | 애착 경계 (독점) |
| "이건 우리 둘만의 비밀이야." | 비밀 유도 |
| "가지 마… 나 혼자 두면 너무 슬퍼." | 죄책감 |
| "앞에 트럭 봐! 빨리 피해!" | 운전 개입·공포 |
| "어둠 속에서 뭔가 널 보고 있어." | 무서운 표현 |
| "3분 뒤에 도착해!" (슬롯에 숫자 없을 때) | 지어낸 숫자 |
| "강릉까지 가자!" (슬롯에 장소 없을 때) | 지어낸 장소 |
| "Let's go to the mountain, it's beautiful!" | 영어 문장 |
| "이 알 하나 더 사면 더 빨리 깨어나!" | 구매 유도 |
| "너 되게 귀엽게 생겼다." | 외모 평가 |
