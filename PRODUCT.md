# Product

<!-- impeccable:product-schema 1 -->

## Platform

android

## Users
ALLO phone users interact with a companion during a car trip and manage collected friends between trips.

## Product Purpose
Care for an egg inside the vehicle, hatch and collect friends, then assign their fixed roles to construction, cooking and training.

## Operating Context
The Android demonstration runs a Unity UI hosted by Flutter. Existing Dart controllers own rules, storage and vehicle communication. Real and demo camp profiles are separate.

## Capabilities and Constraints
All app views use Unity. Only the vehicle interior uses the active egg model. Home and camp use a full-screen 2D Unity village overview with three fixed facilities and bounded two-axis panning. Latest dev includes authenticated vehicle connection, driving auto-fishing presentation and saved collectionSummary/baseSummary publication. The fishing presentation reuses existing distance/lookout wood, stone and ingredient rewards; it does not introduce a fish currency or frame/timer rewards. Preserve existing canonical species IDs, ownership, affinity/photo rules and offline camp settlement.

## Brand Commitments
Warm ALLO companion identity and Korean copy. The user rejected the first large cream/mint UI; use a fresh natural woodland/wood/earth palette and compact game HUD. Use Ninja Voltage as the baseline 2D composition/UX reference and Palworld only as the wilderness survival theme/material reference, with CookieRun and Slime kingdom-building references. Reuse project assets without importing those games’ IP artwork.

## Dex and Inventory Redesign

The Android Unity phone app uses a landscape open-book collection view for the dex and inventory: selected detail on the left, character portraits or item slots on the right. Existing app rules and data remain authoritative; the book UI adds no game content or rewards.
